# 金手指约束

金手指是引擎，不是外挂无限子弹。

## 必填字段（卡片）

| 字段 | 说明 |
|------|------|
| 名称与本质 | 它到底是什么能力 |
| 获得契机 | 为何是 TA |
| 代价 | 每次或累积付出什么 |
| 限制 | 冷却、次数、场合、不可用条件 |
| 成长方式 | 如何变强，是否可预期 |
| 近 5 次使用 | 防止遗忘与膨胀 |
| 代劳比例 | 解决冲突时金手指占比上限建议 |
| 新鲜度计划 | 下一次形态变化何时出现 |

## 使用纪律

- 本章若靠金手指破局，合同中写明；审查时核对代价是否兑现。
- 禁止「刚好有新功能」无登记；新功能 = change request → Canon。
- 连续三章金手指主解冲突 → 强制插入非金手指解题或加重代价。

## Checklist

- [ ] 卡片字段齐全且为 Canon
- [ ] 本章使用已记入资源账本
- [ ] 代价/限制已在正文可见或账本可证
- [ ] 未静默新增功能
