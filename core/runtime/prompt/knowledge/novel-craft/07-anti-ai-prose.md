# 去 AI 味（P0 / P1）

目标：像人写的连载，不像模型作文。

## P0 — 阻断（出现则不得定稿）

- 感悟式/感叹式章末（「或许，这只是个开始……」）
- 上帝视角剧透 POV 不可知信息
- 装饰符号癖（过量 emoji、奇异分隔符、【震惊】标题腔）
- 明显套话堆砌：不禁、宛如、仿佛、令人、深吸一口气、目光深邃、嘴角微微上扬（密集出现）
- 语域乱跳：古风章突然大段现代鸡汤总结

## P1 — 建议修订

- 抽象心理喊情绪代替行为
- 排比三连以上无信息增量
- 代词开头句连发（他……他……他……）
- 全员同一腔调
- 解释型对白（角色互相讲解读者已知设定）

## 操作顺序（Draft C）

1. 删套话与空总结  
2. 改「告诉」为「展示」  
3. 拉开角色对白差异  
4. 章末钩子改成具体未决事件  
5. 再扫一遍 P0  

## Checklist

- [ ] 无 P0  
- [ ] 章末是事件钩子不是鸡汤  
- [ ] 连续抽象情绪句已打散  
- [ ] 未声称「已去 AI」却未改文件
