# 人设与群像

角色是欲望与伤口的载体，不是标签拼盘。

## 主角四件套

1. **欲望**：此刻要什么（可观察）  
2. **伤口**：为何怕失去 / 为何偏执  
3. **手段**：惯用解题方式（智/力/情/骗）  
4. **代价底线**：绝不做或一定会做的事  

## 配角非工具人

- 每个重要配角有独立小目标，与主角目标相交而非附属。
- 出场带「态度」：如何看主角，会否改变。
- 工具型龙套可扁平；反复出场者需增量信息。

## 反派魅力

- 合理的自我正义或结构性压迫，而非纯蠢恶。
- 压迫手段具体；失败后有余波。
- 避免「反派智商忽高忽低」服务剧情。

## 关系网

用关系变化推进剧情：信任增减、秘密共享、债务与恩情。章合同应标注关系进/出状态。

## 知识边界（防 OOC）

POV 角色只能写其可知信息。隐藏设定不得从主角嘴中「刚好猜中」除非合同允许。

## Checklist

- [ ] 主角本章选择符合欲望/伤口
- [ ] 配角有独立动机或明确功能后即退场
- [ ] 无上帝视角剧透 POV 不可知信息
- [ ] 对话有人物指纹（用词/节奏/回避话题）
