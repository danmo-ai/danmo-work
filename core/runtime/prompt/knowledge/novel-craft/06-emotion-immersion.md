# 情绪与代入感

读者追的是情绪曲线，不是事件清单。

## 情绪定调

动笔前先定本章主情绪：爽 / 虐 / 慌 / 暖 / 悚 / 窘。多情绪可以，但要有主次。

## 期待管理

- **承诺**：开篇或卷首暗示的爽点/谜底，要在可感知窗口内推进。
- **延迟**：延迟要加代价或新信息，不能空拖。
- **反转**：反转前每个关键细节应可回看成立（公平戏）。

## 代入技巧

- 具体欲望 + 具体障碍 > 空洞「很努力」。
- 让读者比配角多知道一点或少知道一点（信息差），制造参与感。
- 失败要疼：损失资源、面子、关系或时间。

## Checklist

- [ ] 本章主情绪可命名
- [ ] 有至少一次期待被抬高或落空（有设计）
- [ ] 主角损失/获得对后续有影响
- [ ] 未用旁白直接命令读者感动
