# 世界观与设定一致性

设定是约束，不是词条展览。

## 优先写清的四层

1. **力量/规则**：谁能做什么、代价是什么、上限在哪  
2. **势力地图**：谁占资源、冲突线  
3. **日常物质**：钱、交通、通讯、阶级观感（烟火气）  
4. **禁忌与法律**：碰什么会死 / 会被追杀  

## 一致性原则

- 新设定先查旧规则；冲突则走 **change request**，禁止静默改 Canon。
- 「例外」必须写代价，否则等于无规则。
- 地图与时间线分开维护；跨城/跨日要可核对。

## 展开节奏

- 用冲突逼出设定，少开会解说。
- 同卷内力量体系升级幅度要可预期；暴兵需伏笔或明确代价。

## Checklist

- [ ] 本章新设定与已有规则不打架
- [ ] 战力/资源变化已登记到账本
- [ ] 地点与时间可回溯
- [ ] 未用大段说明书替代场景
