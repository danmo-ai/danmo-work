# 悬疑 / 推理 / 探案 / 刑侦

来源：番茄作家课堂（`fanqie_novel_articles` 索引 + 官方创作宝典）。跨书技法；与「节奏与结构」「爽点与追读」「人设与群像」「题材与平台」交叉引用。

## 定位与 QC

| 子类 | 读者来看 | 正文落到 | QC |
|------|----------|----------|-----|
| 推理探案 | 逻辑解谜、线索回收 | 严密推理 + 意外又合理的结局 | `mystery` |
| 刑侦 | 案件链、职业感、正义兑现 | 单元案串主线；证据链可回看 | `mystery` |
| 灵异风水 | 猎奇、因果、氛围 | 小案升级；超自然不能包打天下 | `mystery` |
| 男频悬疑爽 | 日常细节 + 信息差 + 反转 + 情绪爽 | 接近真相设障碍；结局善恶有报 | `male_power` + `mystery` |
| 女频刑侦 | 破案为主、感情为辅 | 糖葫芦串：一案一结，感情小步进 | `mystery`（关系线见 `female_emotion` 辅维） |

**选题：** 正统悬疑竞品相对少；新人可藏拙切入。规则怪谈多 ≠ 正统悬疑；差异化靠**信息公平 + 逻辑闭环 + 人物成长**。

## 悬疑定义（番茄）

核心在「悬 + 疑」：因未知而怀疑。须备：**曲折情节、强悬念、严逻辑**。不必全程吓人；内容和题材可自由。

### 分支对照

| 分支 | 要素 | 代表作方向 |
|------|------|------------|
| **推理探案** | 严密逻辑解谜；侦探不必是警察；案可非凶杀（寻物、宝藏、离奇事件） | 《心理罪》《法医秦明》 |
| **刑侦** | 刑事案件侦破为主线；主角多为警察/法医/侦探 | 《无证之罪》《长夜难明》 |
| **灵异风水** | 神鬼、探险、因果；朴素「善有善报」；可融考古、周易、民俗 | 《恐怖屋》《鬼吹灯》 |

## 开篇（hard）

与「节奏与结构 → 黄金开篇」叠加：

1. **冲突 / 异常先于设定**：禁止大段背景、专业术语科普、世界观讲座。
2. **露一藏九**：只给现象或结果，不给前因（纸老虎：只给动作，不给原因）。
3. **具体冲突，禁宽泛生死**：「妻子和婆婆同时落水选谁救」> 开篇「被追杀要活命」（读者对主角无感情基础）。
4. **第一页**：硬悬疑可第一句抛信息差（「我前天刚出席了他的葬礼」）；推理可离奇事件 + 限制条件同场。
5. **人物 ≤3–4**，主角占 60%+ 篇幅；主视角锁主角，少跳 POV。

**硬悬疑开篇代价：** 读者因悬疑入坑；若后文变纯爽文、不再悬疑，弃书率高。除非全书定位即悬疑，慎用后文风突变。

## 钩子体系（悬疑向）

通用类型见「爽点与追读 → Hook 类型库」。悬疑额外强调：

| 钩型 | 用法 | 例 |
|------|------|-----|
| 信息缺口 | 读者知 ≠ 主角知，或反之 | 监控里情夫是保安，男主还在保安室查 |
| 结构钩（长线） | 查清 X → 晋升/接近真相 | 三年之约式：每破一案推主线一步 |
| 悬念钩 | 倒计时、未开之门、同一噩梦 | 《三体》倒计时；《别叫我恶魔》天空金门 |
| 反转 | 挖坑须填；多坑可互凑 | 抓到罪犯 → 同手法再犯 → 自杀？ |
| 章节钩 | 章内 80%，结果放下一章头 | 调监控被同事偷笑 — 章末 |

**节奏（徐二家的猫）：** 前 3–4 章快：悬念铺垫 → 小高潮 → 章末再钩；之后放慢取证，**每完成短线，长线推一步**。百万字靠「短线循环 + 长线大爆」。

**新人禁：** 为钩而钩破坏逻辑；伏笔堆太多；一个钩拖太久不揭；揭伏笔时主角突然睿智长篇解说（要「恍然大悟」感，轻飘飘一句更好）。

## 情节设计（悬疑专用）

与「新手急救 / 石头巨怪」一致，写案前必想：

| 技法 | 悬疑应用 |
|------|----------|
| **时间锁** | 限期破案、炸弹倒计时、证物失效时限 |
| **空间锁** | 风雪山庄、封闭现场、空校/医院/酒店；与时间锁叠加 1+1>2 |
| **道德挑战** | 程序正义 vs 结果正义；救一人还是保密钥 |
| **大人物遇小事** | 神探/队长被迫处理「小事」— 信息差或身份反差 |
| **小人物遇大事** | 库管/保安/实习生卷入大案 — 迪化、代入强 |

**推理探案事件：** 线索前后关联，旧道具不能丢；真凶/幕后须有迷惑性，必要时烟雾弹；结局出人意料又情理之中，禁偶发/意外草草收场。

**灵异事件：** 从小离奇切入、环环相扣；禁止「一切都是梦」；超自然存在但**基本逻辑仍须遵循**，真相与叙述同精彩。

## 人物

### 推理 / 刑侦主角

- 高智商 + 敏锐观察力，但须**差异化**（福尔摩斯低情商、薄靳言孤僻），禁千篇一律冷静机智。
- 刑侦写前：**犯罪心理学、真实案例、职业细节**（风雨如书：读教材、请教刑警后再动笔）。
- 开局可普通，随案升级而成长（陈歌：从被保护 → 保护他人）。

### 反派 / 真凶

- 须迷惑性；一出场即被识破 → 失兴趣。
- 男频悬疑爽：反派行为有内在逻辑，甚至让部分读者「理解」（如出轨动机 = 物质稳定 + 新鲜刺激）。

### 女频刑侦（《小山河》）

- **破案为主，感情为辅**：一案结束，感情小步进，立刻下一案。
- 男主**落地**，禁完美全能飘着的神探。
- 可加强亲情/友情线；感情线不可油腻。
- 手写细纲；真实案例库 + 犯罪心理学；数字逻辑弱可**刻意避开时间诡计**。

### 人设落地

人设靠**极端事件中的选择**立住，不靠小传堆砌（京祺）。见「人设与群像 → 四件套 + 三锚点」。

## 氛围（灵异 / 惊悚）

| 手法 | 要点 |
|------|------|
| 人称转换 | 第三人称交代背景；第一人称写恐怖与内心 |
| 信息不对称 | 读者知鬼魂距离，主角不知（《恐怖屋》失明困鬼楼） |
| 反差对比 | 日常场景突然异常（哆啦A梦、放学结伴 → 恐怖降临） |
| 感官钩 | 固定噩梦、血腥味、呼吸声、蛇的眼神与声响、老宅阴沉 |

**代入感：** 把自己带入角色勇敢抒写（《蛇仙》作者）；细节多，写得慢，大纲必做。

## 男频悬疑爽文（2026 风向）

**公式：** 日常细节 + 热点梗 + 三层钩 + 障碍链 + 情绪释放。

| 层 | 内容 | 例（高额电费） |
|----|------|----------------|
| 主钩 | 核心疑问 | 情夫是谁？ |
| 次钩 | 手法疑问 | 如何避开监控？ |
| 情绪钩 | 何时揭晓 | 男主何时发现、读者何时爽 |

**主角：** 普通中年男性、职场边缘人、被辜负者；社会地位高但**思维定势**导致过滤真凶（优秀丈夫不会信老婆出轨保安）。

**节奏：** 每次接近真相设合理障碍，保持「只差一步」；配角反应强化情绪（保安早已知道，偷笑男主）。

**结局：** 意料之外、逻辑之中；善恶有报、扬眉吐气。

**灵感源：** 账单异常、监控、邻里对话等**生活细节** + 平台热点（信息差、身份反转、隐藏真相）。

## 结构与大纲

- **单元剧：** 多案并行，主线在人物关系（《福尔摩斯》《法医秦明》）。
- **升级型：** 小案串大案，幕后层层揭开。
- **女频糖葫芦串：** 一案一结，感情微量推进。
- **推荐字数（新手悬疑）：** 70–80 万写精；大纲剥离法：拆解高分剧人设练手。
- **人物关系表必做**（长篇）：名、关系、性格、作用、结局。

四分法（强调「转」）或破题五分法均可；见「题材与平台」与 plan skill 大纲模板。

## 中期不写崩

都市/刑侦**不宜强行换地图**。靠（「如何稳定剧情」/ 糖糖六公子）：

1. 开篇几万字埋长线伏笔；每 3–10 万字揭一个，循环。
2. 重要配角因冲突退场 → 推新剧情，避免人物只增不减。
3. 环境/语言类小伏笔（时钟、房间大小）可隔几万字揭。

## 平台与审核（悬疑向 hard）

| 禁止 | 处理 |
|------|------|
| 宣传封建迷信（细写做法） | 一笔带过，作批判或反面 |
| 冥婚、结阴亲、怀鬼胎（女频） | 禁 |
| 冰恋（男频） | 禁 |
| 真实地名、政府机关、领导人名称 | 架空 |
| 影射现实政治；领导被超自然杀害 | 禁 |
| 血腥细致、屠城、反人类场面 | 模糊化 |
| 陋习：吃同类、陪葬人殉 | 禁 |
| 以悬疑之名色情；浴室/卧室非必要裸写；鬼魂视角写 | 禁 |
| 重男轻女、吃绝户等 | 仅可作批判对象 |

**三观：** 小说可不够好，三观须正；案件核心是**通过案引导读者**，不是猎奇堆砌（风雨如书）。

## 第一章 Checklist

- [ ] 离奇事件 / 信息差 / 强悬念在场
- [ ] 有名有姓角色 ≤3–4，主角主导
- [ ] 短期目标明确（查谁 / 证什么 / 逃什么）
- [ ] 章末有钩，结果留到下章
- [ ] 无大段世界观 / 专业科普
- [ ] 线索可追踪，反转有铺垫
- [ ] 过审：无真实机构名、无过度血腥、无迷信细写
