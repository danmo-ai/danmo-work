# 悬疑

用未知制造怀疑，再用公平的线索把怀疑解开。推理、刑侦、灵异风水、男频悬疑爽、女频刑侦都是本篇的子类，不另开文件。`novel-state.genre: 悬疑`。

本篇是题材专有文：写正文前 gate preflight 会把本篇整篇打进 CONTEXT；`subgenre=刑侦探案` 时再接「刑侦人味文风」。悬疑或刑侦多出来的规则只写进这两篇，不往共性篇加段落。

黄金三章、露一藏九的通用做法见「节奏与结构」。本篇只写悬疑多出来的切口。单章 `word_share` 2000–3500，主爽点在单元上一次。

## 读者契约与 `qc_profile`

须有曲折、悬念、收得回的逻辑。不必全程吓人。

| 子类 | 读者来看 | 正文落到 | QC |
|------|----------|----------|-----|
| 推理探案 | 逻辑解谜、线索回收 | 严密推理；结局意外但说得通 | `mystery` |
| 刑侦 | 案件链、职业感、正义兑现 | 单元案串主线；证据能回看 | `mystery` |
| 灵异风水 | 猎奇、因果、氛围 | 从小案升级；超自然不能包打 | `mystery` |
| 男频悬疑爽 | 日常细节、信息差、反转、情绪释放 | 快接近真相时设障碍；结局善恶有报 | `male_power` + `mystery` |
| 女频刑侦 | 破案为主、感情为辅 | 一案一结，感情只进一小步 | `mystery`；关系线用 `female_emotion` 做辅维 |

**人味文只跟子类「刑侦探案」：** 刑侦、探案、社会派推理（警察、法医、查案过日子，动机带社会性）写 `subgenre: 刑侦探案`。灵异写「悬疑灵异」，规则怪谈写「规则怪谈」，男频悬疑爽写「悬疑脑洞」，感情为辅的女频刑侦写「女频悬疑」。`mystery` 不是人味开关。人味正文见「刑侦人味文风」，立项不另查那一篇。

规则怪谈多，不等于正统悬疑。差异在信息公平、逻辑闭环、人物会变。

### 子类误挂速查

立项或改类时按下表认主引擎，不凭封面词「刑侦」「悬疑」硬挂：

| 你实际在写 | 正确子类 | 不要 |
|------------|----------|------|
| 警察/法医过日子，公平线索破案 | `刑侦探案`（人味文） | 通灵、见鬼、三炷香破局 |
| 命案皮 + 通灵/玄学微创新破局 | `悬疑灵异`；系统碾压为主 → 系统穿越「悬疑副本」 | `刑侦探案`（七步与人味均不适用） |
| 日常账单/监控/邻里信息差与反转，无办案程序 | `悬疑脑洞`（男频悬疑爽） | 套刑侦七步 |
| 规则副本、假规则推理解谜为主 | `规则怪谈` | 用系统直接报真凶；挂成刑侦探案 |
| 惊悚游戏/诡异复苏且金手指推副本 | 系统穿越「悬疑副本」；公平解谜为主仍改 `规则怪谈` | 刑侦程序 |
| 破案为主、感情每案只挪半步 | `女频悬疑` | 感情盖过破案；男主飘成完美神探 |

短篇课堂里的「破案刑侦 + 玄学」一律按上表第二行处理，**不并入**本篇刑侦办案程序。

## 开篇切口

与「节奏与结构」叠加，悬疑再加这几条：

1. 异常先于设定。禁止专业术语课和世界观讲座。
2. 只给现象或结果，不给前因。
3. 冲突要具体。有感情基础之前，不要用空泛的「被追杀」。
4. 第一页就有信息差，或离奇事件和限制条件在同一场。
5. 有名有姓的人不超过三四个，主角占主要篇幅。视角少跳。

用硬悬疑把人引进来，后文若改成纯爽、不再悬，弃书会高。除非全书就是悬疑，不要中途换味道。

刑侦探案的开篇形状（高能开头 → 写实中段 → 翻转结尾；天气只能参与发现尸体，不能当镜头）见「刑侦人味文风 → 十一、开篇与章末钩子（网文纪律）」。

## 感官钩、时空锁与反差

这一节是悬疑专有的场景写法。通用五感分层和动线见「情绪与场景」。

**感官钩（可回访）：** 固定重复的噩梦片段、只有主角闻得到的血腥味、某双眼睛像蛇。一个钩出现两次以上才算钩，第二次要比第一次多一点信息。

**视线压迫：** 「总觉得背后有人，回头却空的」「明明独处，却感觉被围观」——用虚实交错的错觉加压，不写「诡异」「不祥」。可回访：同一视线感第二次要多一点信息（声源、死角、少了一件物）。

**时间锁 / 空间锁：** 倒计时（天亮前、下一班车、尸体腐败到某一步）或封闭场所（停电的楼、雪封的村、锁死的车厢、审讯室、电梯、密闭楼道）。锁和道德挑战叠一起才紧：出不去，还得决定救谁。锁一旦立下，破锁的手段要在前文可检索。

**环境即线索：** 封闭/半封闭空间里的具体物（米缸、监控死角、门锁痕迹、异常光影）要能进解谜，不当纯布景。删掉仍通的环境穷举删掉。

**反差对比：** 日常场景里突然出现一处不该有的东西（早餐桌上多一副碗筷、监控里多一个人影），比整段阴森描写更刺。反差只用具体物，不用「诡异」「不祥」这类词。

**压迫：** 限制条件同场（不能说、被监视、有时限），氛围靠限制立住，见「情绪与场景 → 氛围 vs 压迫」。

灵异子类的氛围仍靠信息不对称和上面的反差，不靠形容词；真相遵守已经写过的规则。

## 单元上的爽点形态

一个单元推进一条短线：接近真相、设下障碍、揭开一层、长线前进一步。中间章只留信息缺口。不要为了章末钩子改掉已经成立的逻辑。

通用钩型见「爽点与追读」。悬疑额外用得上的是：读者和主角知道的不一样；查清一件事才能碰到更大的事；倒计时或没开的门；抓到人之后同手法再现。伏笔要填。揭开时让人恍然，不要突然长篇解说。

结构三选一，写进单元细纲 yaml 而不是每章一个新故事：多案并行，主线在人物关系；小案串大案（糖葫芦串）；女频一案一结，感情只挪半步。

### 男频悬疑爽（`subgenre: 悬疑脑洞`）

日常账单、监控、邻里对话里长出三层钩——核心疑问、手法疑问、何时揭晓。主角多为被辜负的普通人、职场边缘人或中年弱势位，身份与真相之间留信息差。每次只差一步接近真相时设合理障碍；配角的反应（偷笑、回避、多嘴）把情绪顶上去。

世情反常切口（按单元用，不改章长）：细微反常埋伏笔 → 亲密关系或日常假象 → 逐层撕开人为隐秘 → 取证/反击 → 法理或道德闭环 → 情绪释放。情绪弧：前期「是否误会」→ 中期同情与愤怒同步升 → 后期揭晓与善恶有报。反派行为要有内在账，甚至让一部分读者能懂，结局仍善恶有报。

### 悬疑脑洞变体（与刑侦七步分家）

读者承诺不同，勿混挂「刑侦探案」：

| 变体 | 读者要看 | 正文落到 |
|------|----------|----------|
| 惊悚游戏 | 高死亡率副本、通关/反杀 | 副本惊悚与难度；金手指可助洞察，不能面板报真凶。系统为主 → 改查「系统穿越」悬疑壳 |
| 规则怪谈 | 假规则、矛盾规则、推理解谜 | 信息公平；重在揭开副本规则。见本篇「规则怪谈」纪律 |
| 诡异复苏 | 人鬼两阵营、灵气与威胁同场 | 从小案升级；超自然不能包打真相 |
| 恐怖末世 | 阵营崩溃后的求生与先知优势 | 压迫可有，血腥仍模糊化；先知须贬值 |

系统碾压、签到通关已是主引擎时，改「系统穿越」的「悬疑副本」，本篇只留公平线索那一层。

### 灵异与非刑侦单元节奏

灵异：氛围靠信息不对称和反差（见「感官钩、时空锁与反差」），不靠形容词。真相仍要遵守已经写过的规则。禁止「一切都是梦」。

灵异 / 悬疑脑洞 / 规则怪谈的单元可用循环（**不套刑侦七步**）：危险降临 → 线索排查 → 再度遇险 → 深度排查。每轮排除一批疑点，逼近一层真相；中间章只留信息缺口。

中期不要强行换地图。开篇埋的长线按单元回收。重要配角退场要推出新冲突，不要只加人。

## 刑侦办案程序

仅子类「刑侦探案」。灵异、规则怪谈、悬疑脑洞不套这套步子。女频悬疑可压缩步数，感情仍只挪半步。正文质感见「刑侦人味文风」，只在刑侦探案注入。本节约单元结构，不改人味的闲笔、对话和群像。

### 单元案七步

写进单元细纲，一个单元走完一层，不要拆成每章一个新故事：

1. 案发：现场有一处反常，不先讲前因。
2. 排查：多人有秘密，嫌疑铺开。
3. 第一次锁定，随即推翻。
4. 物证或时间线对不上，疑点升级。
5. 第二层嫌疑人浮出。
6. 逻辑闭合：真凶说得通，前文线索能回看。
7. 收束时埋主线或旧案的下一步。坑要填得完。

### 审讯与对撞

审讯不一次招供：先承认小问题，再瞒关键，最后被一处细节击破。

推翻旧判断，监控、行踪、证词、物证、时间线里至少两样对得上。怀疑要有实锤。突破来自细节、物证、口供漏洞。

每个单元案准备 2–3 个假凶。每人有动机、有疑点、有一段说得圆的嫌疑，最后全部推翻，推翻理由前文已经出现过。

### 三层悬念

- 浅：这一案谁干的。
- 中：动机为何不像情杀、仇杀、财杀。
- 深：和连环、旧案或主线怎么连。

反转落点优先是执念、旧怨、灭口掩盖旧案。第一眼的情仇财可以是假层。真相从主角查到的材料里出来：不写凶手独立心理，不把答案提前交给读者。读者和主角的信息差可以有，揭开时线索必须公平回看。信息差双向见「爽点与追读」。

### 现场与章钩

现场和尸检只写反常与特征：整洁或凌乱过了头、物品错位、出入路径对不上、死亡时间、致死原因、习惯痕迹。施暴过程、逃避追查的做法都不写。

章末仍用「爽点与追读」的 `hook.type`。刑侦只指定切口：

| 切口 | hook.type |
|------|-----------|
| 新物证推翻此前判断 | 突然揭示 |
| 不在场证明出现漏洞 | 信息缺口 |
| 同手法再现，或新的关联案 | 信息缺口 |
| 旧编号、旧人物重现 | 回声/意象 |

被人盯上归信息缺口，凶手留下标记归未兑现承诺。不另造钩型。

## 人设/金手指差异

默认金手指是观察力和信息，不是面板。高智商必须有差别：孤僻、迟钝、某种执念。千篇一律的冷静机智等于没有人。刑侦动笔前要有职业细节和动机来源，不要用档案腔开场。进场规则见「刑侦人味文风」，整篇只在 `subgenre=刑侦探案` 时注入。

真凶要有迷惑性。一出场就被看穿，后面没有悬念。男频爽文里，反派的行为要有他自己的账，甚至让一部分读者能懂，但结局仍要善恶有报。

女频悬疑（`女频悬疑`）：破案为主、感情为辅；一案一结，感情只进一小步，忌油腻感情戏盖过案子。男主落地，不要完美神探飘在案上。亲情、友情可以加。时间诡计不熟就不要用。

人设靠极端局面里的选择，不靠小传。见「人设与群像」。

## 禁止漂移

- 后期改规则、无铺垫突然知道、超自然把案子包收
- 为钩子破坏逻辑；坑开得比填得完还多
- 伏笔揭开时主角突然全知
- 都市或刑侦中途换国家、换地图续命
- 灵异、怪谈、悬疑爽、刑侦+通灵写成子类「刑侦探案」

## 本类型多出来的审核红线

共性见「题材与平台」。本篇写死：

| 禁止 | 处理 |
|------|------|
| 封建迷信的做法写细 | 一笔带过，作批判或反面 |
| 冥婚、结阴亲、怀鬼胎 | 女频禁 |
| 冰恋 | 男频禁 |
| 真实地名、机关、领导人；影射政治；领导被超自然杀害 | 架空，不写 |
| 血腥细致、屠城、吃人、人殉 | 模糊化或禁 |
| 细写作案手法、反侦察做法 | 只写结果、痕迹、反常 |
| 凶手独立视角提前交出真相 | 限知；线索公平回看 |
| 执法体系集体作恶、抹黑公检法 | 个人可以有私心和错；体系保持正面 |
| 借悬疑写色情；浴室卧室非必要的裸写；鬼魂视角写这些 | 禁 |
| 重男轻女、吃绝户 | 只能当被反对的对象 |

案子要能把读者带去一个说得通的判断，不是猎奇堆砌。三观要正：作品影响读者判断方向，猎奇不能压过可辨的是非。

## 来源
