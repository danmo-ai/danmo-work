# 文风与去 AI 味

文风是可复用资产：先锁定，再写章。定稿必须像人写的连载。

## 视角与画面

- **有限第三人称**（网文常见）：贴主角感知，利于悬念。
- **第一人称**：声音强，但知情人边界更严。
- 一章内不乱切上帝视角；多 POV 需在合同标明。
- 优先：动作、对话、感官细节 → 再补判断。少用抽象总结句。

## 对话指纹

- 每人有口头禅/回避点/信息密度差异。
- 对话推进利益或揭示性格；删除纯复述已知信息的对白。

## 文风分层（可记入 project memory）

| 倾向 | 特征 | 适合 |
|------|------|------|
| 热血爽文 | 短句、快切、释放密 | 玄幻升级 |
| 都市烟火 | 生活细节、对白自然 | 都市/职场 |
| 古风意境 | 留白、比兴、战写意 | 仙侠古言 |
| 悬疑压抑 | 信息克制、环境压迫 | 悬疑灵异 |

## P0 — 阻断（出现则不得定稿）

- 感悟式/感叹式章末（「或许，这只是个开始……」）
- 上帝视角剧透 POV 不可知信息
- 装饰符号癖（过量 emoji、奇异分隔符、【震惊】标题腔）
- 明显套话堆砌：不禁、宛如、仿佛、令人、深吸一口气、目光深邃、嘴角微微上扬（密集出现）
- 语域乱跳：古风章突然大段现代鸡汤总结

## P1 — 建议修订

- 抽象心理喊情绪代替行为
- 排比三连以上无信息增量
- 代词开头句连发（他……他……他……）
- 全员同一腔调
- 解释型对白（角色互相讲解读者已知设定）

## 操作顺序

1. 删套话与空总结
2. 改「告诉」为「展示」
3. 拉开角色对白差异
4. 章末钩子改成具体未决事件
5. 再扫一遍 P0

## Checklist

- [ ] 视角稳定，对白可区分
- [ ] 无 P0
- [ ] 章末是事件钩子不是鸡汤
- [ ] 未声称「已去 AI」却未改文件
