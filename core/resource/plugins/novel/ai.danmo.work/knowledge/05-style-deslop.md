# 文风与去 AI 味

文风是可复用资产：先锁定，再写章。定稿必须像人写的连载。

## 视角与画面

- **有限第三人称**（网文常见）：贴主角感知，利于悬念。
- **第一人称**：声音强，但知情人边界更严。
- 一章内不乱切上帝视角；多 POV 需在合同标明。
- 优先：动作、对话、感官细节 → 再补判断。少用抽象总结句。

## 对话指纹

- 每人有口头禅/回避点/信息密度差异。
- 对话推进利益或揭示性格；删除纯复述已知信息的对白。

## 文风分层（可记入 project memory）

| 倾向 | 特征 | 适合 |
|------|------|------|
| 热血爽文 | 短句、快切、释放密 | 玄幻升级 |
| 都市烟火 | 生活细节、对白自然 | 都市/职场 |
| 古风意境 | 留白、比兴、战写意 | 仙侠古言 |
| 悬疑压抑 | 信息克制、环境压迫 | 悬疑灵异 |

## P0 — 阻断（出现则不得定稿）

- 感悟式/感叹式章末（「或许，这只是个开始……」「反击才刚刚开始」）
- 上帝视角剧透 POV 不可知信息
- 装饰符号癖（过量 emoji、奇异分隔符、【震惊】标题腔）
- 语域乱跳：古风章突然大段现代鸡汤总结
- 下列**毒句式出现 1 处**，或 **一级词密集 ≥3 处**：

| 毒句式 | 修法 |
|--------|------|
| 「不是 A，而是 B」 | 直接写 B |
| 「，带着一丝/一抹……」 | 删状语或改动作 |
| 「声音不大，却带着……」 | 写台词或具体声线 |
| 「他/她知道 / 终于明白……」 | 用行为展示 |
| 「眼中闪过 / 嘴角勾起 / 心中涌起」 | 垂眼、嘴角一扯、身体反应 |
| 「他不知道的是……」空预告 | 改成具体未决事件 |

**一级词（出现即换，勿整章同义复读）：** 仿佛、犹如、宛若、不禁、深吸一口气、目光深邃、不容置疑、前所未有、话锋一转、心中暗道、指节泛白、瞳孔微缩。

## P1 — 建议修订

- 抽象心理喊情绪代替行为
- 排比三连以上无信息增量
- 代词开头句连发（他……他……他……）
- 全员同一腔调
- 解释型对白（角色互相讲解读者已知设定）
- **二级密度**：缓缓 / 微微 / 轻轻 / 淡淡 每千字合计 >3；突然 / 猛地 连发
- 「这一刻」「从这一刻开始」「命运的齿轮/獠牙」总结腔

## 操作顺序

1. 删套话与空总结
2. 改「告诉」为「展示」
3. 拉开角色对白差异
4. 章末钩子改成具体未决事件
5. 再扫一遍 P0

## Checklist

- [ ] 视角稳定，对白可区分
- [ ] 无 P0
- [ ] 章末是事件钩子不是鸡汤
- [ ] 未声称「已去 AI」却未改文件
