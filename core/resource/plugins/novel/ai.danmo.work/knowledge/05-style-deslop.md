# 文风与去 AI 味

文风是可复用资产：先锁定，再写章。定稿必须像人写的连载。
「AI 味」的本质不是用错词，而是**没有脉搏**：无观点、无混乱、无具体、无不确定。

## 视角与画面

- **有限第三人称**（网文常见）：贴主角感知，利于悬念。
- **第一人称**：声音强，但知情人边界更严——不得知道他人想法。
- 一章内不乱切上帝视角；多 POV 需在章纲标明；全知视角换头必须有场景分隔；时态切换每章 ≤1 次。
- 优先：动作、对话、感官细节 → 再补判断。少用抽象总结句。

## 对话指纹

- 每人有口头禅/回避点/信息密度差异；遮掉人名也能听出是谁（遮名测试）。
- 对话推进利益或揭示性格；删除纯复述已知信息的对白；解释型对白（"as you know, Bob"）是缺陷。

## 文风分层（可记入 project memory）

| 倾向 | 特征 | 适合 |
|------|------|------|
| 热血爽文 | 短句、快切、释放密 | 玄幻升级 |
| 都市烟火 | 生活细节、对白自然 | 都市/职场 |
| 古风意境 | 留白、比兴、战写意 | 仙侠古言 |
| 悬疑压抑 | 信息克制、环境压迫 | 悬疑灵异 |

## 量化硬指标（gate `precommit`/`scan-deslop` 硬检）

阈值以 `novel_gate.py` 顶部常量为准（单一事实源），本节与其保持一致：

| 指标 | 阈值 | 级别 |
|------|------|------|
| 破折号「——」密度 | ≤5 个/千字；单段 >2 个重写该段 | **blocking**（长篇第一大中文 AI 指纹） |
| 英文泄漏（中文行文混入英文单词，白名单 OK/APP 等除外） | 0 | **blocking** |
| 中文 AI 禁词表命中（见下） | 0 | **blocking** |
| 比喻词 像是/仿佛/好像 | ≤2 个/段 且 ≤8 个/章 | 超章限 **blocking** |
| 「不是X，是Y / 不是A，而是B」句式 | ≤1 次/章 | 超出 blocking |
| 四字格 | ≤2 个/段，不连用 | 文档层（审稿人工判） |
| 同一句式结构连发（SVO, SVO, SVO） | 禁 3+ 连续 | 文档层 |
| 二级密度词 缓缓/轻轻/淡淡 | 合计 ≤3 个/千字 | P1 advisory |

**自检四计数**：审稿/润色报告必须带 `em_dash_count / ai_vocab_count / english_leak_count / simile_count`（gate `### COUNTS` 直接给出，引用即可）。

## 中文 AI 禁词表（命中即 blocking）

某种、微微、嘴角微微上扬、勾起一抹弧度、不由自主、空气仿佛凝固、气氛一时之间、声音沙哑、声音低沉（模板化出场描写）、目光深邃、目光锐利。

> 一级词与禁词表并集生效；禁词表是「即判即死」子集。

## P0 — 阻断（出现则不得定稿）

- 感悟式/感叹式章末（「或许，这只是个开始……」「反击才刚刚开始」）
- 上帝视角剧透 POV 不可知信息
- 装饰符号癖（过量 emoji、奇异分隔符、【震惊】标题腔）
- 语域乱跳：古风章突然大段现代鸡汤总结
- 客服腔/旁白跳出（「希望这对您有帮助」式收尾、markdown 语法泄漏进正文）
- 量化硬指标任一 blocking 项超标
- 下列**毒句式出现 1 处**，或 **一级词密集 ≥3 处**：

| 毒句式 | 修法 |
|--------|------|
| 「不是 A，而是 B」（全章 >1 次） | 直接写 B |
| 「，带着一丝/一抹……」 | 删状语或改动作 |
| 「声音不大，却带着……」 | 写台词或具体声线 |
| 「他/她知道 / 终于明白……」 | 用行为展示 |
| 「眼中闪过 / 嘴角勾起 / 心中涌起」 | 垂眼、嘴角一扯、身体反应 |
| 「他不知道的是……」空预告 | 改成具体未决事件 |

**一级词（出现即换，勿整章同义复读）：** 仿佛、犹如、宛若、不禁、深吸一口气、目光深邃、不容置疑、前所未有、话锋一转、心中暗道、指节泛白、瞳孔微缩。

## P1 — 建议修订

- 抽象心理喊情绪代替行为（「他感到悲伤」→ 分级生理动作：轻度 咬牙/吞咽；中度 手抖/声音破；重度 砸拳/腿软）
- 排比三连以上无信息增量；否定排比（「不是简单的X，而是Y更是Z」）
- 代词开头句连发（他……他……他……）
- 全员同一腔调
- 解释型对白（角色互相讲解读者已知设定）
- **二级密度**：缓缓 / 轻轻 / 淡淡 每千字合计 >3；突然 / 猛地 连发（「微微」已入禁词表，不在此列）
- 「这一刻」「从这一刻开始」「命运的齿轮/獠牙」总结腔
- 过渡词链（首先…其次…值得注意的是…综上所述）
- 假范围（「从X到Y，无一不……」）、空泛结尾

## 解药：写出脉搏

1. **要有观点**——叙述者对人事有态度，不中立播报。
2. **放进杂乱**——允许离题半句、半生不熟的念头、没说出口的话。
3. **要具体**——「横断左眉的疤」而非「英俊」；具体物件、具体数字。
4. **变化节奏**——句长、段长、信息密度高低交替。
5. **承认复杂**——不确定和矛盾是特性，不是要抹平的瑕疵。
6. **情绪用身体写**——用分级生理动作替代抽象情绪命名。

## 操作顺序

1. 跑 gate `scan-deslop` 拿 `### HITS` + `### COUNTS`
2. 先修 blocking（禁词/破折号/英文泄漏/比喻超限/毒句式）
3. 删套话与空总结，改「告诉」为「展示」
4. 拉开角色对白差异，章末钩子改成具体未决事件
5. 复扫 exit 0，报告引用四个计数

## Checklist

- [ ] 视角稳定，对白可区分（遮名测试通过）
- [ ] gate scan-deslop exit 0，四计数在阈值内
- [ ] 无 P0，禁词表零命中
- [ ] 章末是事件钩子不是鸡汤
- [ ] 未声称「已去 AI」却未改文件
