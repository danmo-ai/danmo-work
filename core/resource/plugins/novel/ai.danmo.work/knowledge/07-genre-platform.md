# 题材与平台

选题对齐题材气味；审稿按 `qc_profile` 加权；番茄向写法服务留人。

## 题材短画像

**玄幻 / 东方幻想** — 升级可见、地图扩张、势力博弈。风险：说明书、无代价暴兵。开篇：冲突 + 金手指同时出现。QC：`male_power`

**都市** — 现实压力、智斗/资源/身份、烟火细节。风险：开挂无社会代价。开篇：具体利益冲突。QC：`male_power` 或 `general`

**仙侠** — 境界与执念、意象战斗、人情劫。风险：堆仙名、战力口水。开篇：执念比等级表重要。QC：`male_power` 或 `general`

**言情 / 古言** — 关系推进、拉扯与错位。风险：人设崩、甜虐无因果。开篇：关系张力先于世界观。QC：`female_emotion`

**悬疑 / 灵异** — 信息公平、线索回收、氛围压迫。风险：后期乱加规则。开篇：异常事件 + 限制条件。QC：`mystery`

**系统流 / 穿越** — 规则游戏感、任务节奏。风险：系统代打、无人物。开篇：规则代价与主角选择同时立住。QC：`male_power`

## QC Profile

读 `novel-state.yaml` 的 `qc_profile`；默认 `general`。

| Profile | 适用 | 优先维度 |
|---------|------|----------|
| `male_power` | 男频爽文、玄幻、都市逆袭 | 爽点兑现、升级反馈、节奏、期待链、钩子 |
| `female_emotion` | 女频情感、古言、甜虐 | 关系推进、情绪兑现、人物选择、对话张力 |
| `mystery` | 悬疑、灵异、规则怪谈 | 证据公平、信息差、反转可信度、氛围 |
| `general` | 未指定或混合 | 连贯、角色、节奏、钩子、语言 |

门槛：`male_power` 钩子口号 → P0；连续 2 章爽点 <5（开篇）→ blocking。`female_emotion` 人设崩 → blocking。`mystery` 无铺垫获知 → blocking。

## 题材正文落点（写前对照，勿写进正文）

每题材只取一行：边界 + 落点 + 禁漂移。跨题材时主题材 1 行，辅题材只摘「禁漂移」。

| 题材 | 读者来看 | 正文落到 | 禁止漂移 |
|------|----------|----------|----------|
| 玄幻 / 东方幻想 | 升级可见、地图扩、势力博弈 | 冲突里带出境界/地图；打完有缴获或声望 | 说明书开篇；无代价暴兵；越级秒顶级 |
| 都市 | 利益、智斗、烟火 | 具体账单/职位/面子；能力有社会代价 | 开挂无人问；全程会议室解说 |
| 仙侠 | 执念、人情劫、写意战 | 一劫一执念；战写意象+代价，少堆仙名 | 等级表开篇；战力口水 |
| 言情 / 古言 | 关系拉扯、错位 | 选择改变关系；对白有潜台词 | 旁白宣布相爱；人设服务剧情 |
| 悬疑 / 灵异 | 公平线索、氛围 | 异常+限制同场；线索可回看 | 后期改规则；无铺垫获知 |
| 系统 / 穿越 | 规则游戏、任务节奏 | 规则代价与选择同时立住；面板 ≤3 行 | 系统代打关键抉择 |

番茄战神 / 赘婿 / 当面打脸：亲自出手就是契约，不能用「幕后运筹」给主角划水。布局 / 权谋 / 群像 / 导师：默认可借力，但因果权与结算权仍须可见（「强约束」）。

## 番茄平台（免费网文）

收入绑读时长与完读率：留人 > 一切。

- **章字数 2000–3500**；每章末必有钩。
- **爽点密度**：每 3–5 章至少一个；开篇期每 2–3 章一个。
- **第一章前 300 字**：主角+冲突+金手指气味到场。
- **前三章**一个完整爽点闭环。
- **接钩**：下一章开头 500 字内接住上一章钩。
- **段短句短**：一屏 3–5 段，单段不超过 3 行。
