# 题材与平台

题材已经落在下面八个标题里时，立项只查那个标题，不要查本篇。题材还对不上，才查本篇，把切口收进其中一篇。

武侠不单开，差在「仙侠」。脑洞不单开，变体在「系统穿越」。推理、灵异、刑侦不单开，子类在「悬疑」。人味不是类型：只有刑侦、探案、社会派在「悬疑」里标 `craft_lane=crime-human`。

## 八个类型

| 检索标题 | `qc_profile` | 禁止漂移 |
|----------|----------------|----------|
| 玄幻 | `male_power` | 说明书开篇；无代价暴兵；越级秒顶级 |
| 仙侠 | `male_power` 或 `general` | 等级表开篇；战力口水；日常写成一潭死水 |
| 都市 | `male_power` 或 `general` | 开挂无人问；全程会议室解说 |
| 悬疑 | `mystery`；爽向叠加 `male_power` | 后期改规则；无铺垫获知；超自然包收尾 |
| 现代言情 | `female_emotion` | 旁白宣布相爱；人设只为推剧情 |
| 古代言情 | `female_emotion` | 现代化口吻；报应拖过读者耐心；圣母原谅 |
| 仕途扫黑 | `general` 或 `male_power`；查案叠加 `mystery` | 影射现实；开篇说明书；高光被机构无声夺走 |
| 系统穿越 | `male_power`；关系是主引擎时改 `female_emotion` | 系统代打关键抉择；面板刷屏 |

## QC 加权

读 `novel-state.yaml` 的 `qc_profile`；默认 `general`。`craft_lane`（`default` | `crime-human`）与 QC 独立。

| Profile | 适用 | 优先维度 |
|---------|------|----------|
| `male_power` | 男频爽文、玄幻、都市逆袭 | 爽点兑现、升级反馈、节奏、期待链、钩子 |
| `female_emotion` | 女频情感、古言、甜虐 | 关系推进、情绪兑现、人物选择、对话张力 |
| `mystery` | 悬疑、灵异、规则怪谈 | 证据公平、信息差、反转可信度、氛围 |
| `general` | 未指定或混合 | 连贯、角色、节奏、钩子、语言 |

门槛：`male_power` 钩子口号 → P0。`female_emotion` 人设崩 → blocking。`mystery` 无铺垫获知 → blocking。

当面打脸（战神、赘婿）：亲自出手才算兑现，不能用幕后运筹给主角划水。布局、权谋、群像可以借力，因果权和结算权仍须看得见。前者见「都市」，后者见「仕途扫黑」和「强约束」。

## 番茄留人共性

留人靠读完，不靠平台条款。

- 单章 `word_share` 2000–3500。单元 `word_target` 是各章之和。一份单元正文是为了章间衔接，不把单章写长。
- 主爽点写在单元上一次。中间章只要 `cut_hook`。章间单独一行 `---`。
- 黄金三章、露一藏九见「节奏与结构」，不在本篇重写。
- 段短、句短。一屏几段，单段不要写成墙。

先写自己写得顺的气味，再对齐榜单。热点会过。立项时把擅长标签写进读者承诺，不要写成「这个月什么火写什么」。

## 审核红线共性

类型多出来的红线写在各篇。下面是共用的：

- 禁真实地名、政府机关、领导人名称；禁影射现实政治
- 禁把封建迷信写成可操作的细教程；女频禁冥婚、结阴亲、怀鬼胎；男频禁冰恋
- 血腥模糊化；禁屠城和反人类场面；禁借类型写色情
- 正义须走得通的规则落地。扫黑不能靠私刑或超自然代替
