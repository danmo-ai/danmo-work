# 人设与群像

角色是欲望与伤口的载体，不是标签拼盘。

## 主角四件套

人物卡用 `novel-setup/assets/templates/cast-card.md`（欲望 / 伤口 / 手段 / 底线 + 知识边界 + 退场）。配角可只填目标与相交点。

1. **欲望**：此刻要什么（可观察）
2. **伤口**：为何怕失去 / 为何偏执
3. **手段**：惯用解题方式（智/力/情/骗）
4. **代价底线**：绝不做或一定会做的事

## 配角非工具人

- 每个重要配角有独立小目标，与主角目标相交而非附属。
- 出场带「态度」：如何看主角，会否改变。
- 工具型龙套可扁平；反复出场者需增量信息。

## 反派层级

按出场篇幅选层，禁止「小反派当全书 Boss 写」或「大 Boss 降智送赢」。

| 层级 | 篇幅 | 必有 |
|------|------|------|
| 小反派 | 1–5 章 | 1–2 个鲜明特征，干脆退场 |
| 卷对手 | 约 10–30 章 | 动机说得通；至少赢主角一次 |
| 大弧 Boss | 一卷或数卷 | 理念冲突 + 绝境战 + 失败余波 |
| 最终 Boss | 全书 | 第一章就有气味；代表主题反面 |

建立顺序：实力展示 → 动机可信 → 真实威胁 → 真意图留到反转。反派智商决定主角含金量。

## 感情线（有则填；无感情主线可跳过）

四阶段，勿跳级：相识气味 → 试探/错位 → 临界（信任或决裂）→ 确认或永失。每阶段至少一个**可见选择**，禁止旁白宣布「他们相爱了」。

男频极简：感情是战果或代价，不抢主爽点循环。女频：关系推进本身就是主引擎，QC 见「题材与平台」`female_emotion`。

## 关系网

用关系变化推进剧情：信任增减、秘密共享、债务与恩情。章合同 `state_deltas` 写关系进/出。

动机链（卡文时用）：起因（具体事件）→ 意图 → 约束 → 失败代价。起因禁止「被欺负」这种空话。

## 知识边界（防 OOC）

POV 角色只能写其可知信息。隐藏设定不得从主角嘴中「刚好猜中」除非合同允许。

## Checklist

- [ ] 主角本章选择符合欲望/伤口
- [ ] 配角有独立动机或明确功能后即退场
- [ ] 反派层级与篇幅匹配；卷对手至少赢过一次
- [ ] 有感情线则未跳阶段、有可见选择
- [ ] 无上帝视角剧透 POV 不可知信息
- [ ] 对话有人物指纹（用词/节奏/回避话题）
