# 人设与群像

角色是欲望与伤口的载体，不是标签拼盘。人设靠**剧情碰撞中的选择**立住，小传写完 ≠ 立住。

## 角色功能分工（写前先定）

| 角色 | 优先 | 含义 | 禁 |
|------|------|------|----|
| 主角 | **功能性 > 完美性** | 身上有别人做不到的事（金手指、信息差、独特手段）；不完美才生剧情 | 开局全能无缺口 |
| 配角 | **记忆点 > 完整性** | 抓 1 个独特锚点（嗜甜暗卫、结巴毒医）；描写少，防抢戏 | 配角简历式铺满 |
| 反派 | **破坏力 > 邪恶值** | 必须实际施压（修为/权势/情报）；菜鸡再坏也不是反派 | 只骂不伤、降智送赢 |

## 主角四件套

人物卡用 `novel-setup/assets/templates/cast-card.md`（欲望 / 伤口 / 手段 / 底线 + 矛盾 / 弧光 + **视觉/语言/行为三锚点** + 知识边界 + 退场）。配角可只填目标与相交点。

1. **欲望**：此刻要什么（可观察）
2. **伤口**：为何怕失去 / 为何偏执
3. **手段**：惯用解题方式（智/力/情/骗）
4. **代价底线**：绝不做或一定会做的事（=「不妥协点」；写到极致才有记忆）

### 人物模型速填（开书表格）

每出一个重要角色至少记：姓名 · 年龄跨度 · 明暗身份 · **动态外貌习惯**（禁静态目录）· **记忆锚点**（疤/口头禅/配饰）· 家庭背景气味 · 情感联系（亲/友/恋各 1 条即可）。背景越复杂，可延伸剧情越多；身份过简 → 剧情易平。

## 矛盾与弧光（人物 ≠ 原型）

- **矛盾**是区分「人物」与「原型」的关键：同一角色身上必须存在两处真实张力——「战场上勇敢，爱情里怯懦」「最恨谎言，却靠谎言谋生」。没有矛盾的角色只是功能。
- **弧光**三态：起点 → 当前 → 预期终点（含**拒绝改变**的反向弧——别人成长，他守住/崩于原念）。弧光靠选择推进，不靠旁白宣布。
- 偏差许可制：行为偏离四件套当且仅当（被戏剧化为成长时刻 / 外力逼迫 / 同章或下一章被点明）。忘记设定、剧情强扭人物、无戏内解释 → OOC。

### 性格：单一强化（非多重堆砌）

长篇人物多，读者记不住「既善良又勇敢又聪明又雷厉风行」。**配角与卷对手：性格单一并反复强化**（莽就莽到底）。多重性格留给篇幅够长的主角；除非巨大变故，勿章间性格翻转。性格须符合成长环境与身份；**思想核心 = 追求**——不断设障阻止其追求，人物才活。

### 反差标签法（快速立人）

外表标签 × 内里标签，表面可反差，底层须自洽（伏笔或经历可解释）：

| 层 | 写什么 | 例 |
|----|--------|-----|
| 身份 | 明面 vs 暗面 | 面馆老板 / 风水师 |
| 性格 | 浓缩标签，靠事件兑现 | 清冷 × 嘴毒；柔弱 × 扛事 |
| 价值态度 | 积极/消极甚至自相矛盾 | 厌世却仍救人 |

习惯、喜恶、口头禅是记忆点，也是后文伏笔锚（怕猫 → 被设局；嗜鸡 → 玩世不恭标签）。

## 气质三锚点（防 OOC / 人设漂移）

每个反复出场的角色锁定三个可观察锚，写进人物卡，章内至少兑现 1 个：

| 锚 | 写什么 | 崩了的样子 |
|----|--------|------------|
| 视觉 | 标志外貌、物件、姿态 | 换脸换装无交代 |
| 语言 | 口头禅、回避点、句子长短 | 全员同一腔调 |
| 行为 | 压力下的习惯动作 | 性格标签与临场选择相反 |

三锚点是「读者认人」的钩子，四件套是「角色为什么行动」。不要用「气场强大」代替视觉锚。一个特征动作胜过通篇形容词（坏人摸痣上的毛琢磨害人）。

## 活人感四法（防扁平）

| 法 | 做法 | 禁 |
|----|------|----|
| **填过往** | 回忆/伏笔穿插解释动机；一点一点放 | 一次性倒完；与性格/剧情无关的回忆 |
| **加细节** | 动作、微表情、袖口攥紧的手指 > 「他很生气」 | 每句对白都堆动作 |
| **添成长** | 困境 → 挣扎 → 改变 → 沉淀；可贴遗憾 | 无理由一蹴而就；懦弱瞬间无所畏惧 |
| **赋配角灵魂** | 配角有目标/烦恼/短支线，可与主线交织 | 少数工具人反复横跳；作用结束仍占戏 |

成长可分：主角主线成长 / 配角辅助成长 / 反派反向成长（非洗白，是动机更复杂：嫉妒→放手、仇恨→悲情）。

## 配角非工具人

- **删除测试**：把这个配角删掉，故事就崩——才配留下；删掉无影响 → 合并或删。
- 每个重要配角有独立小目标，与主角目标相交而非附属。
- 出场带「态度」：如何看主角，会否改变。
- 工具型龙套可扁平；反复出场者需增量信息。
- 同功能角色合并；死亡与退场的后果须与角色分量成正比——不为震惊值杀人，为故事价值杀人。
- 写配角时**暂时当主角写**：出身、处境、他会如何应对——才鲜活。

### 配角功能六型（一个角色可兼）

| 功能 | 作用 | 例 |
|------|------|-----|
| Confidant 心腹 | 让主角说出内心 | Watson |
| Foil 对照 | 反衬主角选择 | Draco |
| Catalyst 催化 | 触发事件后让位 | 报信人 |
| Mirror 镜像 | 主角的另一条人生路径 | — |
| Stakes anchor 代价锚 | 让读者在乎输赢 | 家人/徒弟 |
| Comic relief 缓冲 | 调节节奏，不破氛围 | — |

## 反派层级

按出场篇幅选层，禁止「小反派当全书 Boss 写」或「大 Boss 降智送赢」。

| 层级 | 篇幅 | 必有 |
|------|------|------|
| 小反派 | 1–5 章 | 1–2 个鲜明特征，干脆退场 |
| 卷对手 | 约 10–30 章 | 动机说得通；至少赢主角一次 |
| 大弧 Boss | 一卷或数卷 | 理念冲突 + 绝境战 + 失败余波 |
| 最终 Boss | 全书 | 第一章就有气味；代表主题反面 |

建立顺序：实力展示 → 动机可信 → 真实威胁 → 真意图留到反转。反派智商决定主角含金量。

### 反派动机光谱（选型用，决定写法难度）

| 类型 | 内核 | 备注 |
|------|------|------|
| 理念型 | 自洽世界观，认为自己在行善 | 最引人注目，首选 |
| 创伤型 | 伤口驱动，以伤害回应伤害 | 与主角镜像时最强 |
| 系统型 | 体制/规则本身作恶，人是齿轮 | 适合群像与社会派 |
| 镜像型 | 主角的反面教材「若主角走岔」 | 张力天然 |
| 虚无型 | 无动机之恶 | 最难写，慎用 |

最好的反派认为自己是自己故事的主角：有独立于主角的欲望与恐惧、能胜任的威胁、与主角的私人关联。

## 出场方法（首出场定生死）

**有效四种**：行动中出场 / 冲突中出场 / 矛盾中出场（言行不一）/ 他人眼中出场（借第三方评价）。

**动态描写优先于静态**：声 → 在场者反应 → 入场簇拥/动作 → 再点容貌（王熙凤式），比从头到脚外貌目录更难忘。

**禁用四种**：照镜子自描、简历式罗列设定、起床日常开场、无语境的外貌目录。

## 群像管理

- **出场预算**：同屏角色宁少勿多；新角色入场须有功能名分。
- **轮换焦点**：非 POV 重要角色连续出场 ≤3 章，之后须轮换或给新信息增量。
- 关系网每对都要有张力源；禁止静态关系——每对关系必须演变。
- 开书用表记录人设，防重叠与遗忘（群像百万字以上尤甚）。

## 感情线（有则填；无感情主线可跳过）

四阶段，勿跳级：相识气味 → 试探/错位 → 临界（信任或决裂）→ 确认或永失。每阶段至少一个**可见选择**，禁止旁白宣布「他们相爱了」。

男频极简：感情是战果或代价，不抢主爽点循环。女频：关系推进本身就是主引擎，QC 见「题材与平台」`female_emotion`。

### CP：天然冲突 + 致命吸引

言情/有感情线时，**把 CP 当整体设计**，再填单人卡：

| 要素 | 做什么 | 缺了会怎样 |
|------|--------|------------|
| **天然冲突** | 三观、立场、社会身份、伦理、阶级至少占 1–2 维 | 糖写不长或硬凑 |
| **致命吸引** | 学识/性情/经历互补等，忌纯血药强绑 | 感情干、莫名其妙在一起 |

CP 类型可参考：一见钟情 / 日久生情 / 由恨生爱 / 步步为营。关系可参考：单暗 / 双暗 / 明恋 / 一爱一恨 / 被迫绑定。副 CP、男配女配线用不同「类型×关系」组合，防同质。冲突也适用于主角 vs 配角、对立。

## 关系网

用关系变化推进剧情：信任增减、秘密共享、债务与恩情。章纲 `state_deltas` 写关系进/出。

**关系三要素**（缺一不可）：不对称（双方想要的东西不同）+ 张力源（利益/秘密/权力差）+ 必须演变（静态关系禁止）。

动机链（卡文时用）：起因（具体事件）→ 意图 → 约束 → 失败代价。起因禁止「被欺负」这种空话。

## 知识边界（防 OOC）

POV 角色只能写其可知信息。隐藏设定不得从主角嘴中「刚好猜中」除非章纲允许。

## Checklist

- [ ] 主角本章选择符合欲望/伤口；偏差有戏内解释（偏差许可制）
- [ ] 主角有功能缺口；配角有记忆点；反派有破坏力
- [ ] 主要角色有矛盾点；性格单一强化或反差自洽；弧光按选择推进
- [ ] 活人感：过往穿插非倾倒；情绪用动作/神态非形容词堆
- [ ] 配角通过删除测试，有独立动机或明确功能后即退场
- [ ] 反派层级与篇幅匹配；卷对手至少赢过一次；动机光谱选型明确
- [ ] 新角色出场用有效四法之一（优先动态）；未用禁用四法
- [ ] 非 POV 重要角色连续出场 ≤3 章
- [ ] 有感情线：未跳阶段、有可见选择；CP 冲突+吸引双在
- [ ] 无上帝视角剧透 POV 不可知信息
- [ ] 对话有人物指纹（用词/节奏/回避话题）
- [ ] 上场角色能对上至少 1 个三锚点（视觉/语言/行为）
