# 题材速览（短画像）

用于选题与文风对齐；非百科。写具体题材时再 `search_kb` 细规则或查资料。

## 玄幻 / 东方幻想

- 承诺：升级可见、地图扩张、势力博弈。  
- 风险：设定说明书、无代价暴兵、同构打脸。  
- 开篇：冲突 + 金手指约束同时出现。  
- QC profile：`male_power`（见 KB 题材 QC Profile）

## 都市

- 承诺：现实压力、智斗/资源/身份、烟火细节。  
- 风险：开挂无社会代价、对话像公文。  
- 开篇：具体利益冲突（钱/权/脸/案）。  
- QC profile：`male_power` 或 `general`

## 仙侠

- 承诺：境界与执念、意象战斗、人情劫。  
- 风险：堆仙名、战力口水、感情工具化。  
- 开篇：执念或因果比等级表重要。  
- QC profile：`male_power` 或 `general`

## 言情 / 古言

- 承诺：关系推进、拉扯与错位、情绪密度。  
- 风险：人设崩、工具人配角、甜虐无因果。  
- 开篇：关系张力先于世界观。  
- QC profile：`female_emotion`

## 悬疑 / 灵异

- 承诺：信息公平、线索回收、氛围压迫。  
- 风险：后期乱加规则、主角开挂读心。  
- 开篇：异常事件 + 限制条件。  
- QC profile：`mystery`

## 系统流 / 穿越

- 承诺：规则游戏感、任务节奏、成长可见。  
- 风险：系统代打、任务清单体、无人物。  
- 开篇：规则代价与主角选择同时立住。  
- QC profile：`male_power`；场景见 KB 场景专项（系统流）

## Checklist

- [ ] 读者承诺与平台/篇幅匹配
- [ ] 开篇兑现题材「气味」
- [ ] 主风险点已在大纲中规避
