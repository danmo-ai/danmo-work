# 世界观与金手指

设定是约束，不是词条展览。金手指是引擎，不是外挂无限子弹。

## 优先写清的四层

落盘 `canon/world.md`（模板 `novel-setup/assets/templates/world.md`），不要另起一套结构。

1. **力量/规则**：谁能做什么、代价是什么、上限在哪
2. **势力地图**：谁占资源、冲突线
3. **日常物质**：钱、交通、通讯、阶级观感（烟火气）
4. **禁忌与法律**：碰什么会死 / 会被追杀

## 一致性

- 新设定先查旧规则；冲突则走 **change request**，禁止静默改 Canon。
- 「例外」必须写代价，否则等于无规则。
- 地图与时间线分开维护；跨城/跨日要可核对。
- 用冲突逼出设定，少开会解说。

## 金手指卡片（必填）

| 字段 | 说明 |
|------|------|
| 名称与本质 | 它到底是什么能力 |
| 获得契机 | 为何是 TA |
| 代价 | 每次或累积付出什么 |
| 限制 | 冷却、次数、场合、不可用条件 |
| 成长方式 | 如何变强，是否可预期 |
| 近 5 次使用 | 防止遗忘与膨胀 |
| 代劳比例 | 解决冲突时金手指占比上限建议 |
| 新鲜度计划 | 下一次形态变化何时出现 |

## 使用纪律

- 本章若靠金手指破局，合同中写明；审查时核对代价是否兑现。
- 禁止「刚好有新功能」无登记；新功能 = change request → Canon。
- 连续三章金手指主解冲突 → 强制插入非金手指解题或加重代价。

## 战力防崩（升级台阶）

- 敌人 / 地图 / 境界成**梯队**，禁止越级秒顶级。
- 开书算一次：体系档数 × 每档停留篇幅 ≥ 全书目标字数；不够就加层，不靠每章憋。
- 金手指、身份、社会地位四点要统一（见主角卡 + 圣经终局储备）。触顶 = 动用终局底牌，须到解锁卷。
