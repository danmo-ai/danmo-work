# 刑侦人味文风

总纲一句：**人是先于案子的，案子是撞进人的生活里的。** 读者为人追书，不为案卷追书。

情节 / 钩 / 审核深描仍用「悬疑 / 推理 / 探案 / 刑侦」。本篇只管**正文质感与改写**。

## 一、人物进场：靠动作和误会，不靠档案

禁止新人物第一场戏出现「年龄 + 学历 + 职务」连续陈述。可给：他做了什么、别人怎么称呼他、身上一件具体物（磨亮的背包肩带）。

**背景信息三个给法**（读者需要、人物早已知道的）：

1. **拆散了给** — 只在当下需要的时刻给那一块。
2. **借有提问权的人的嘴给** — 新人、记者、家属、好奇辅警；刑警/记者是合法提问者。
3. **在情绪戏里夹带给** — 激动时抖旧事，读者顾着心疼。

学历背景等露本事后再由别人半句带出。信息延迟释放 = 悬念。

## 二、情绪：走外部行为，不点名情绪

禁止代办词通知紧张：「心里一凛 / 心提到嗓子眼 / 后脖颈汗毛立起来 / 咯噔」。

按身体反应分级：

| 级 | 写法例 |
|----|--------|
| 轻 | 想掏烟，想起轮不到他先掏，手在膝盖上蹭了蹭 |
| 中 | 答话慢半拍；端起茶碗发现是空的 |
| 重 | 站起来时条凳腿在地上刮出一声响 |

与「情绪与场景 → 用场景烘托情绪」同向；本篇刑侦向一律按行为写。

## 三、叙述者闭嘴三不：不解释、不划线、不总结

画面刚立起，禁止解说员上台：「这套家谱是真的」「饵撒出去了，鱼现在来问了」「来了。」

判断：删掉这一句，上下文是否仍通顺、信息是否仍成立？成立 → 删。

伦纳德总开关：**如果读起来像「写作」，就重写。** 省略读者会跳过的厚段落——写完先问会不会跳，会则删或拆。

## 四、对话允许低效

真人说话有废话、答非所问、半句、说完后悔。害怕的人尤其低效（报不出完整话、挂电话抽半根烟再打）。审讯/试探里被问方可反问、装傻、扯到饭上。

**对话纪律：**

- 引导词只用「说」，偶用「问」「答」。禁止「他沉声低吼道」「她冷冷地讥讽道」——语气由台词 + 小动作承担。
- 感叹号全书限量（约 ≤2–3 / 十万字）。
- 方言靠词汇与语序（「你给瞅瞅」「娃他舅」），不靠拼音拼写；一句对白方言词至多一个。
- 要口语**节奏**，不要录音垃圾（满篇嗯呃半截）。
- **遮名测试**：盖住名字分不出谁 → 回去补人物，不是补台词。

与「情绪与场景 → 对话场景」叠加：效用测试仍要；刑侦向允许「低效但有性格」的废话，禁止庭审记录式一来一往。

## 五、每场戏留一处闲笔

闲笔 = 不推进破案、但让世界活过来的细节。一场 ≥1 处，一章 ≥3 处。删了不影响破案，但读者会少记住场景。

**闲笔埋命运：** 每卷给主要人物一件「随身物」或「口头习惯」，结局回响一次（如「水捞饭」意象）。

**细节库工作法：** 日常读新闻/聊天遇到的活细节先记库，写作时按场景取，不现场编造。

边界：精选一两处，非环境穷举。枝桠要完整、能映主线——完整枝桠替情节分担密度。

## 六、物质世界质感（刑侦专用）

「人味」一半在物上。常备：

- **局里**：卷宗潮味、印泥、搪瓷缸隔夜茶、值班硬板床、吱呀电扇、结案率考核表、推销保险电话。
- **现场**：警戒线颜色与声、勘查灯、福尔马林混泥土味、雨后车辙、一次性鞋套。
- **法医**：摘手套动作、解剖室排风扇、验尸补贴拖欠。
- **日子**：季节天气按真实时间；警察吃饭睡觉、工资有数、家里有等门的人。

年代文靠物立时代：BP 机、桑塔纳、夏利、供销社、搪瓷红字。

**取舍——「离地半米」：** 不照相写实，追求「看起来很对」。选有表现力的一两件，让读者闻到味儿，不做笔录。

## 七、死者要写生前

死者不是线索容器。每起命案至少一处生前琐碎（未发出的草稿、欠小卖部十七块、牙刷还湿）。无名氏案可反过来：「连张脸都没给留」。

## 八、警察是职业，也是日子

禁止全员功能人（队长=发火拍板，法医=报数据，新人=露本事）。

单位生态：使唤新人、法医抱怨早饭、技术中队被当修打印机、现场嘟囔加班。允许矛盾情绪：敬业又烦、同情又怕家属。

**程序真实感取舍（故事优先）：**

- 读者**看不见**可简化：内部审批、检验周期、跨地文书。
- 读者**看得见**必须对：进场顺序、询问口气、上下级说话、新人权限。
- 主角须频繁越程序 → 造规则自留地（专案组 / 技术顾问 / 特聘），设定一次全程豁免，比次次硬闯可信。

## 九、动机要有社会性

松本清张内核：动机之外加社会性；紫金陈同构——普通人遇天大难处与不公，自带戏剧冲突。

1. **好人困境写到数字**：「验尸补贴拖欠半年，津贴 38 块」>「警察很穷」。
2. **恶人来路走得通**：堕落每一步「情有可原」（收钱为妻子换肾）。
3. **反派逻辑自己说圆**：不认为自己是坏人，读者才发凉。

## 十、群像：视线不能只长在主角头上

社会派排斥名侦探独角戏。视线分散给警察、法医、记者、报案普通人——一起拼真相。

- **主角全知纪律**：重生/金手指必须贬值；推理含误判可能；只用此刻合理知情。主角永远正确 = 无悬念。
- **配角每人一件「过不去的事」**：执念立群像，时代分量落到人头上。

## 十一、开篇与章末钩子（网文纪律）

**开篇：** 高能开头 → 写实中段（仿佛身边）→ 翻转结尾。不用天气**当**开头（雾参与发现尸体 = 戏的一部分，合法；纯写景天气镜头删）。

**章末钩：** 章字数服从本书 `word_target` / 平台默认（番茄 2000–3500）。钩子占**末 100–200 字**。五类：

1. 动作截断（手按在门把上）
2. 反转揭秘（须前文埋线，禁空降）
3. 未知危机（小麻烦刚了，更大露头）
4. 信息遮断（只给结果不给原因）
5. 关键信息压尾（最重信息压末句）

**节奏：** 1 强 2 缓交替；2–3 章一个高能钩，中间小疑问维持。禁：谜语人钩、空钩子、埋了不兑现。

**位置分工：** 钩子放章尾，人味放过程。过程里人物活、日子流，最后三段收紧出钩——前面越松，钩越狠。

通用钩型库见「爽点与追读」；悬疑钩体系见「悬疑 / 推理 / 探案 / 刑侦」。

## 十二、节拍器加严（仅严于 gate 的 advisory）

比喻密度、tic 词、「不是 X 而是 Y」、破折号 **blocking** 仍只认 `novel_gate.py`。下列可再压，超了不单独 FAIL 定稿：

| 项 | 人味向上限 |
|----|------------|
| 破折号（——） | ≤2 处/千字（gate 仍是 ≤5/千字才 blocking） |
| 「突然」「霎时」「就在那一刻」 | 一章 ≤1，能删则删 |
| 感叹号 | ≤2–3 / 十万字 |
| 「来了。」「他知道。」「晚了。」类单句打点 | 一章 ≤2 |
| 「亏得…」三连排比 | 全文 ≤2 组 |
| 四字情绪词（心潮澎湃/百感交集） | 全文 ≤2 |
| 情绪代办词（心里一凛/心提到嗓子眼/汗毛立起/咯噔） | 0 |

正文禁用 Markdown 记号；引号/省略号与原作一致，续写不露接缝。

## 改写对照速查

| 生硬 | 人味 |
|------|------|
| 他心里一凛 | 想掏烟，想起轮不到他先掏，手在膝盖上蹭了蹭 |
| 陆沉，二十六岁，公大硕士 | 行政科追着喊三楼打印机又卡了，老王替他挡：「人命关天。」 |
| 饵撒出去了，鱼现在来问了 | （删，直接写下一场） |
| 老太太，人死不能复生，节哀 | 笔尖顿了顿，还是把「自杀」两个字写下去了 |
| 她非常害怕 | 电话打了两遍。第一遍接通，说不出话，挂了，抽半根烟，又打 |
| 他贪婪残忍，为钱杀人 | 他收第一笔钱，是为了给妻子换肾 |
| 警察很穷 | 验尸补贴拖欠半年，津贴 38 块 |
| 突然，门外传来一声巨响 | 门外一声巨响。（「突然」本身是减速带） |

核心手法：**动作顶替情绪、数字顶替形容词。**

## Checklist（刑侦章）

- [ ] 新人物无档案式进场；背景拆散 / 借嘴 / 夹情绪
- [ ] 无情绪代办词；情绪走行为分级
- [ ] 无旁白认证/划线/总结；删了仍通顺的句已删
- [ ] 对话有低效与性格；遮名可辨；引导词克制
- [ ] 本章 ≥3 处闲笔；主线人物有随身物/口头习惯可回声
- [ ] 物象「离地半米」；死者有生前琐碎
- [ ] 警察有日子与矛盾情绪；可见程序对、不可见可简化
- [ ] 动机有社会性数字/来路；反派能说圆
- [ ] 非主角独角戏；主角可误判
- [ ] 章末钩具体；过程人味、尾段收紧
- [ ] 节拍器密度未八股；无 Markdown 泄漏
