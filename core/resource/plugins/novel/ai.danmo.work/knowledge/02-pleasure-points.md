# 爽点与疲劳管理

爽点是读者情绪的闭环释放，不是无脑堆「打脸」。

## 基本闭环

`压抑 → 蓄势 → 释放`。缺压抑则廉价；缺蓄势则突兀；只释放则审美疲劳。

## 打脸四拍（可用变体）

1. 嘲讽 / 轻视  
2. 主角沉默或示弱（蓄）  
3. 碾压或反证（放）  
4. 围观 / 后果扩散（余韵）

## 密度与升级链

- 同级重复打脸超过 2–3 次需换形态或升对立层级。
- 对立升级示例：同窗 → 长辈 → 宗门 → 天才 → 大势力。
- 每卷至少换一种主爽点形态（智斗 / 战力 / 感情 / 身份）。

## 防疲劳

- 连续大爽后插入喘息或代价。
- 金手指代劳比例过高时降「爽感可信度」。
- 读者已知结局的桥段要换信息差或代价差。

## Checklist

- [ ] 本章至少一处可命名的情绪释放（或明确「蓄势章」）
- [ ] 释放前有可见压抑/代价
- [ ] 未连续三章同构打脸
- [ ] 金手指未无代价解决本章全部冲突
