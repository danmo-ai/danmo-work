# 爽点与追读

爽点是读者情绪的闭环释放；追读靠具体钩子和及时微兑现。

## 两个层级（先分清，别混）

本文有两类节奏，层级不同，别把它们当一回事：

| 层级 | 叫什么 | 频率 | 在哪管 |
|------|--------|------|--------|
| **段级波动** | 信息/压力/关系位移 | 每 300–500 字一次（见「节奏与结构」） | 正文段落推进，不是爽点 |
| **章级爽点** | 可命名的情绪释放 | 每 2–3 章一次（开篇段），见下表 | 单元/章纲 `pleasure_point` |

- 段级波动是"读者不觉得平"，章级爽点是"读者有情绪回报"。
- 段级波动**不是**爽点；章级爽点**不靠**堆波动代替。
- 番茄向更密：段级波动可收紧到每 ~1000 字一个微钩，章级爽点仍 2–3 章一次。

## 释放链

`压抑 → 蓄势 → 释放 → 余韵`。缺压抑则廉价；缺蓄势则突兀；只释放则疲劳。

**打脸**是释放链的一种变体，不是另一套百科：嘲讽 → 示弱蓄势 → 碾压/反证 → 围观扩散。同级打脸超过 2–3 次换形态或升对立层级（同窗 → 长辈 → 宗门 → 天才 → 大势力）。每卷至少换一种主爽点形态（智斗 / 战力 / 感情 / 身份）。

**防疲劳**：连续大爽后插入喘息或代价；金手指代劳过多则降可信度；读者已知结局的桥段改打信息差或代价差。

## Hook 类型库

单元细纲 `next_hook.type` 必须从上表选；`next_hook.out` 写具体事件，禁止口号。中间章的 `cut_hook` 也是具体切口，类型可短，不必每章另选一条主爽点。六类为骨架，后三行为缺口补型。

| 类型 | 位置 | 定义 | 章末/章首示例 |
|------|------|------|----------------|
| 信息缺口 | 均可 | 知道「有事」，不知「是什么」 | 门后传来不属于任何人的呼吸 |
| 未兑现承诺 | 章末 | 角色当众/对读者承诺即将发生 | 明日午时，当众验骨 |
| 高代价选择 | 章末 | 两难，选哪边都疼 | 救妹妹还是保密钥 |
| 身份反转 | 章末 | 身份标签即将翻转 | 他摘下面具——竟是失踪三年的兄长 |
| 关系临界 | 章末 | 信任/敌意到达临界点 | 她第一次把刀递向他喉咙 |
| 倒计时 | 均可 | 明确时间压力 | 离阵法崩塌还有三刻 |
| 未完成动作 | 章末 | 动作做到一半切断 | 刀已出鞘，对面的人却笑了 |
| 突然揭示 | 章末 | 新事实落地，解释未给 | 匣子里不是丹药，是一封他的死讯 |
| 回声/意象 | 均可 | 同一物件/句子，含义已变 | 那枚铜钱又出现在枕边 |

**章首接法**（不是新的 `hook.type`）：下一章开头 **500 字内** 用动作或对话接住上一章 `cut_hook`（单元第一场接上一单元 `next_hook.out`），禁止复述章末金句。

## 结构钩与悬念钩（期待层，不是新的 hook.type）

`next_hook.type` 管**单元末事件钩**。跨单元的期待另用「结构钩 / 悬念钩」规划，写进总纲或卷纲索引/结构钩，不要另造第二套 enum。

| 层 | 定义 | 写法 | 禁 |
|----|------|------|----|
| **开篇钩** | 第一章建立期待（露一藏九） | 冲突现场 + 未解异常；见「节奏与结构」 | 开篇拆光全部设定 |
| **结构钩** | 短/长期目标灯塔，指引读者「朝哪走」 | 长线：三年之约、治病、复仇；短线：考入学院、拿一枚异火。长短线并行，间隔勿过长 | 设了目标不了了之；无正向回馈 |
| **悬念钩** | 未知驱动好奇 | 倒计时、只露门不开门、只给现象不给前因 | 假悬念（威胁立刻解除） |
| **章钩** | = 上表 `hook.type` + `hook.out` | 具体事件 | 口号钩 |

**结构钩纪律：** 钩子是照亮故事的脉冲星，不是骗读者点下一章的假饵。目标可未达成，但须给努力以可见回馈（换奖励、抬 stakes、或明确失败代价）。一个结构钩兑现后，马上挂上下一个。

**信息差双向：**

- 读者 > 角色：读者等掉马/等灾难落地（暗牌、上帝视角半拍）。
- 读者 < 角色：关键信息延迟披露（信上写了什么暂不写全）。

段落层配方见下「段落钩」；题材向结构钩举例见悬疑/仕途深描篇。

### 情绪 → 钩子

动笔前看章纲主情绪，优先选：

| 主情绪 | 优先 hook.type |
|--------|----------------|
| 爽 | 身份反转、突然揭示、未兑现承诺 |
| 虐 | 高代价选择、关系临界 |
| 慌 | 倒计时、未完成动作、信息缺口 |
| 暖 | 关系临界、回声/意象 |
| 悚 | 信息缺口、突然揭示、回声/意象 |
| 窘 | 未兑现承诺、身份反转 |

## 微兑现与钩子债务

- 每章至少 **1 个微兑现**：小爽点、小信息、小情绪释放。
- **接钩**：见上「章首接法」（番茄向 blocking）。
- **债务上限**：同时开放债务 ≤5 条；超过必须兑现或降级为伏笔。
- 一批章纲：**连续 3 章 `pleasure_point` 为空必须重排**。

| 阶段 | 爽点密度 |
|------|----------|
| 开篇 1–30 章 | 每 2–3 章至少 1 个明确爽点 |
| 稳定连载 | 每 3–5 章至少 1 个 |
| 卷末高潮前 | 可压缩到 2 章 1 爽，勿连续 3 章纯铺垫 |

### 速写公式（仅两条）

- **章末**：谁 + 正要做什么 + 差临门一脚（写成 `hook.out` 一句）。
- **章首**：用动作/对白接 `hook.out`，500 字内给微兑现或加压，不复述上章结尾。

## 段落钩（章内微钩，不是新的 hook.type）

章纲 `hook` 只管章末。段内用下面配方，一章最多主用 1–2 种，禁止连续 3 章同型。

| 配方 | 一句话 | 禁 |
|------|--------|----|
| 信息差 | 读者知道、角色不知道（或反过来） | 拖过约 3000 字不揭 |
| 暗牌 | 主角藏了一手，读者等亮牌 | 藏过本单元还不打 |
| 倒计时 | 明确时限 | 到期不兑 = 假悬念 |
| 代价 | 按下发送键的同时失去什么 | 最后什么都没丢 |
| 打脸 | 对方正在得意，一句话翻盘 | 同级连打 3 次 |
| 异常物件 | 不该在这里的东西 | 只吓唬不回收 |

禁忌：假悬念（威胁立刻解除）、机械降神（章尾危、章首巧合救）、低风险钩（无关紧要的事）。

## 对话占比（文档纪律，非 gate）

全章对白字数占正文过高时，后期最容易变成「聊天注水」。默认带（审稿人工判）：

| 章型 | 对白建议上限 |
|------|--------------|
| 悬疑氛围 / 开篇立世界 | ≤25–30% |
| 一般推进章 | ≤35% |
| 战斗 / 对抗章 | ≤30% |
| 过渡 / 谈判章 | ≤40–45% |

超 50% 优先砍复述已知信息的对白，补动作与环境。**风格分支：** `qc_profile: female_emotion` 的心理拉扯章可放宽到约 45%，但仍禁止整章纯复读；见「现代言情」。

## 叙事循环报警

下列模式在全书中**同构重复 ≥3 次**且无形态升级时，须换解法或升对立层级：

| 模式 | 同构症状 |
|------|----------|
| 觉醒–升级–新敌人 | 每段只靠新面板/新境界过关，无人物代价变化 |
| 敌人有苦衷 → 话疗收束 | 对峙后发现被操控，几句共鸣倒戈（见「强约束」话疗） |
| 探索新图一笔带过 | 换地图只逛规则，无单元级兑现 |

升级流允许「平台升高」，但须换爽点形态（智斗 / 战力 / 身份 / 关系）或换代价种类，见上「防疲劳」。

### 风格 1 · 番茄男频爽向（`qc_profile: male_power` 且目标平台番茄）

不写进无条件共性绝对句。本轨额外加压：

- 大篇章（约一卷量级）至少一次**不可逆损失**（人/物/地位/关系），禁止全程零代价通关。
- 约每 10 章至少一次主角**亲手决策或亲手对抗**（不是只看面板/放壳）。
- 约每 10 章至少一次**撕裂式情绪**（怒/崩溃/当场丢脸），禁止长期只有温馨底色。
- 收束章禁止「全员轮流归档」的群像模板；反派须能说话、能博弈，不能全是哑巴沙袋。

### 风格 2 · 女频情感向 / 甜宠

安全感与关系推进优先，见「现代言情」「古代言情」。不要求永久牺牲与撕裂密度；仍遵守话疗禁令与对话注水上限的放宽分支。

## Checklist

- [ ] 本章至少一处可命名的情绪释放（或明确「蓄势章」）
- [ ] 释放前有可见压抑/代价
- [ ] `hook.type` 在上表；`hook.out` 具体且下一章可接
- [ ] 开放钩子债务 ≤5
- [ ] 结构钩（长短线目标）未断链；信息差未拖过约 3000 字不揭
- [ ] 对话占比未失控；同构循环未连发 3 次无升级
- [ ] male_power 番茄向：对照风格 1 四条
