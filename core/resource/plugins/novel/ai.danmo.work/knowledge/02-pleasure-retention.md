# 爽点与追读

爽点是读者情绪的闭环释放；追读靠具体钩子和及时微兑现。

## 释放链

`压抑 → 蓄势 → 释放 → 余韵`。缺压抑则廉价；缺蓄势则突兀；只释放则疲劳。

**打脸**是释放链的一种变体，不是另一套百科：嘲讽 → 示弱蓄势 → 碾压/反证 → 围观扩散。同级打脸超过 2–3 次换形态或升对立层级（同窗 → 长辈 → 宗门 → 天才 → 大势力）。每卷至少换一种主爽点形态（智斗 / 战力 / 感情 / 身份）。

**防疲劳**：连续大爽后插入喘息或代价；金手指代劳过多则降可信度；读者已知结局的桥段改打信息差或代价差。

## Hook 类型库

章纲 `hook.type` 必须从上表选；`hook.out` 写具体事件，禁止口号。六类为骨架，后三行为缺口补型。

| 类型 | 位置 | 定义 | 章末/章首示例 |
|------|------|------|----------------|
| 信息缺口 | 均可 | 知道「有事」，不知「是什么」 | 门后传来不属于任何人的呼吸 |
| 未兑现承诺 | 章末 | 角色当众/对读者承诺即将发生 | 明日午时，当众验骨 |
| 高代价选择 | 章末 | 两难，选哪边都疼 | 救妹妹还是保密钥 |
| 身份反转 | 章末 | 身份标签即将翻转 | 他摘下面具——竟是失踪三年的兄长 |
| 关系临界 | 章末 | 信任/敌意到达临界点 | 她第一次把刀递向他喉咙 |
| 倒计时 | 均可 | 明确时间压力 | 离阵法崩塌还有三刻 |
| 未完成动作 | 章末 | 动作做到一半切断 | 刀已出鞘，对面的人却笑了 |
| 突然揭示 | 章末 | 新事实落地，解释未给 | 匣子里不是丹药，是一封他的死讯 |
| 回声/意象 | 均可 | 同一物件/句子，含义已变 | 那枚铜钱又出现在枕边 |

**章首接法**（不是新的 `hook.type`）：下一章开头 **500 字内** 用动作或对话接住上一章 `hook.out`，禁止复述章末金句。

### 情绪 → 钩子

动笔前看章纲主情绪，优先选：

| 主情绪 | 优先 hook.type |
|--------|----------------|
| 爽 | 身份反转、突然揭示、未兑现承诺 |
| 虐 | 高代价选择、关系临界 |
| 慌 | 倒计时、未完成动作、信息缺口 |
| 暖 | 关系临界、回声/意象 |
| 悚 | 信息缺口、突然揭示、回声/意象 |
| 窘 | 未兑现承诺、身份反转 |

## 微兑现与钩子债务

- 每章至少 **1 个微兑现**：小爽点、小信息、小情绪释放。
- **接钩**：见上「章首接法」（番茄向 blocking）。
- **债务上限**：同时开放债务 ≤5 条；超过必须兑现或降级为伏笔。
- 一批章纲：**连续 3 章 `pleasure_point` 为空必须重排**。

| 阶段 | 爽点密度 |
|------|----------|
| 开篇 1–30 章 | 每 2–3 章至少 1 个明确爽点 |
| 稳定连载 | 每 3–5 章至少 1 个 |
| 卷末高潮前 | 可压缩到 2 章 1 爽，勿连续 3 章纯铺垫 |

### 速写公式（仅两条）

- **章末**：谁 + 正要做什么 + 差临门一脚（写成 `hook.out` 一句）。
- **章首**：用动作/对白接 `hook.out`，500 字内给微兑现或加压，不复述上章结尾。

## 段落钩（章内微钩，不是新的 hook.type）

章纲 `hook` 只管章末。段内用下面配方，一章最多主用 1–2 种，禁止连续 3 章同型。

| 配方 | 一句话 | 禁 |
|------|--------|----|
| 信息差 | 读者知道、角色不知道（或反过来） | 拖过约 3000 字不揭 |
| 暗牌 | 主角藏了一手，读者等亮牌 | 藏过本单元还不打 |
| 倒计时 | 明确时限 | 到期不兑 = 假悬念 |
| 代价 | 按下发送键的同时失去什么 | 最后什么都没丢 |
| 打脸 | 对方正在得意，一句话翻盘 | 同级连打 3 次 |
| 异常物件 | 不该在这里的东西 | 只吓唬不回收 |

禁忌：假悬念（威胁立刻解除）、机械降神（章尾危、章首巧合救）、低风险钩（无关紧要的事）。

## Checklist

- [ ] 本章至少一处可命名的情绪释放（或明确「蓄势章」）
- [ ] 释放前有可见压抑/代价
- [ ] `hook.type` 在上表；`hook.out` 具体且下一章可接
- [ ] 开放钩子债务 ≤5
