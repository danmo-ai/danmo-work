# 追读力与钩子债务

目标：让读者「停不下来」——断章钩具体、微兑现及时、债务可追踪。

## Hook 类型库

| 类型 | 定义 | 章末示例 |
|------|------|----------|
| 信息缺口 | 读者知道「有事」，不知「是什么」 | 门后传来不属于任何人的呼吸 |
| 未兑现承诺 | 角色当众/对读者承诺即将发生 | 明日午时，当众验骨 |
| 高代价选择 | 两难，选哪边都疼 | 救妹妹还是保密钥 |
| 身份反转 | 身份标签即将翻转 | 他摘下面具——竟是失踪三年的兄长 |
| 关系临界 | 信任/敌意到达临界点 | 她第一次把刀递向他喉咙 |
| 倒计时 | 明确时间压力 | 离阵法崩塌还有三刻 |

章合同 `hook.type` 必须从上表选；`hook.out` 写具体事件，禁止口号。

## 微兑现

- 每章至少 **1 个微兑现**：小爽点、小信息、小情绪释放（不必是大高潮）。
- 大爽点（打脸/升级/身份揭露）按卷纲节奏；微兑现填章内 300–500 字波动。
- 合同字段 `micro_payoff`：本章读者「尝到」的具体收益。

## 钩子债务（reader_debts）

- 每个未接钩的章末悬念 = 一笔债务；`table_*` collection `reader_debts` 或合同 `reader_debt` 列表追踪。
- **接钩规则**：下一章开头 **500 字内** 必须接住上一章 `hook.out`（番茄向 blocking）。
- **债务上限**：同时开放债务 ≤5 条；超过必须在本章或下章兑现或降级为伏笔（记入 foreshadows）。

## 爽点密度（近 5 章）

| 阶段 | 要求 |
|------|------|
| 开篇 1–30 章 | 每 2–3 章至少 1 个明确爽点 |
| 稳定连载 | 每 3–5 章至少 1 个 |
| 卷末高潮前 | 可压缩到 2 章 1 爽，但勿连续 3 章纯铺垫 |

审稿 **ReaderPull** 透镜：查近 5 章爽点分布 + 开放债务数 + 接钩是否及时。

## Checklist

- [ ] 本章 `hook.out` 具体且下一章可接
- [ ] 本章有 `micro_payoff` 或 `pleasure_point` 正文兑现
- [ ] 开放钩子债务 ≤5
- [ ] 若续上一章钩，开头 500 字内已接
