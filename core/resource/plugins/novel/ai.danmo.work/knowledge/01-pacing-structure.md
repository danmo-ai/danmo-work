# 节奏与结构

长篇连载靠节奏留人：开篇抓人、章中推进、章末留钩。

## 黄金开篇（前三章）

1. **冲突先于设定**：前 500 字进入利益冲突或悬念，少说明书。
2. **读者承诺清晰**：这本看爽、看虐、看悬疑？第一章就要兑现气味。
3. **主角能动**：主动选择 > 被动挨打解说。
4. **信息分层**：世界观用行动带出，不堆名词表。

## 断章钩子类型

- 信息缺口（刚揭一半）
- 未兑现承诺（答应的事未发生）
- 高代价选择（二选一未决）
- 身份/地位反转临界点
- 关系破裂或靠近的瞬间
- 倒计时/伤势/期限将至

## 卷与章节奏

- **卷**：一个清晰升级目标 + 一次主高潮 + 若干中钩。
- **章**（网文常见 3k–4k）：起冲突 → 加压 → 小释放或反转 → 钩子。
- 每 3–5 章至少一个「情绪释放点」；连续三章纯铺垫通常过拖。

## Checklist

- [ ] 开篇 3 句内有画面或冲突
- [ ] 本章目的一句话能说清
- [ ] 章末有可感知钩子（非空喊「下一章更精彩」）
- [ ] 本卷高潮位置在大纲中已标出
