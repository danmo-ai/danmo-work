# 节奏与结构

长篇连载靠节奏留人：开篇抓人、章中推进、章末留钩。钩子类型与密度见「爽点与追读」。终局台阶与透支判定见「强约束」。

## 黄金开篇（前三章）

开篇三基点并成一条清单，前 500 字必须落地气味：

1. **冲突先于设定**：进入利益冲突或悬念，少说明书。
2. **读者承诺清晰**：这本看爽、看虐、看悬疑？第一章就要兑现气味。
3. **主角能动**：主动选择 > 被动挨打解说。
4. **信息分层**：世界观用行动带出，不堆名词表。

**禁项（开篇即失败）：** 世界观说明书、名词表点名、被动挨打后长解说、题材公式套模具。题材只定**切口**（第一场冲突从哪进），不定章法模具。

开篇顺序（可删不可乱）：情节钩子 → 陷入异常 → 金手指气味 → 欲望/矛盾运转 → 本卷目标立住。

前三章合同阶段：`search_kb` 本篇；写钩子前改查「爽点与追读」。逐章执行清单见 `novel-write/references/opening-chapters.md`。

## 黄金三章执行清单（逐章交付）

与上文「开篇顺序」配合：顺序管 **信息进场**，下表管 **每章必须交什么**。

| 章 | 核心交付 | 章末读者应能回答 |
|----|----------|------------------|
| ch1 | 冲突在场、主角能动、题材气味、具体钩 | 「这人是谁、正在什么麻烦里、这类书什么味？」 |
| ch2 | stakes 抬高；小代价 **或** 小胜利可见；钩 | 「比上一章更糟/更难/更近了什么？」 |
| ch3 | 一个完整释放闭环（压抑→蓄势→释放→余韵） | 「这类书主要看主角用什么方式推进？」 |

**ch1 前 300 字（番茄向 hard）：** 主角身份可辨 + 利益/生命/关系冲突 + 金手指或核心异常 **气味** 同场或紧接。

**ch3 闭环尺度：** 不必卷级高潮，但须 **可命名**（合同 `pleasure_point` 非空且正文兑现）；禁止把终局底牌提前打光。

**跨章：** 每章冲突 **形态** 应变化（换场景/对手层级/矛盾类型），禁止三章同一打脸模板。

## 章内节奏

单章（常见 2000–3500 字）内部也要有波动，不能「平推到底、章末才钩」。审稿 `PacingDensity` 据此判。

### 四段式（章内比例）

| 段 | 约占章 | 任务 | 读者感受 |
|----|--------|------|----------|
| 入场 | 0–15% | 接钩或立场景；谁在哪、要什么 | 立刻知道「这一章从哪开始」 |
| 加压 | 15–70% | 障碍递增、信息差、关系位移 | 比章首更紧 |
| 小释放/反转 | 70–90% | 小胜/小败/半揭/代价落地 | 情绪有一个落点 |
| 章末钩 | 90–100% | 未完成动作或新 stakes | 想翻页 |

「小释放」可以是虐释放（失去什么）或爽释放（赢一小步）；蓄势章可把「小释放」换成 **显性代价**（仍须有落点）。

### 300–500 字波动

**规则：** 任意连续 **300–500 字** 内，至少出现以下 **一项**：

- 新信息（事实、规则、关系变化）
- 新压力（时限、对手、资源减少）
- 关系位移（信任±、站队、潜台词兑现）
- 感官/场景切换（见「情绪与场景 → 场景沉浸」）

**禁止：** 同一情绪强度下纯描写堆叠 >500 字无推进；同一解释型对白 >3 轮无新信息。

### 铺垫密度

| 章类型 | 写法 | 合同标记 |
|--------|------|----------|
| 推进章 | 每 300–500 字波动；章内至少 1 次小释放 | 默认 |
| 蓄势章 | 允许延迟大释放，但每 **800–1000 字** 须有微推进（小代价/新线索/关系临界）；章末钩仍须具体 | 合同 `purpose` 含「蓄势章」 |
| 纯铺垫章 | **禁止连续 3 章**（`PacingDensity` blocking）；两章蓄势后下一章必须可命名释放 |

蓄势不是「什么都不发生」，而是 **大释放延后 + 微推进不断**。

### 段长与屏效（番茄向）

单段 ≤3 行；一屏 3–5 段。长段独白/说明 >5 行 → 拆段或改动作/对白。

## 五步锁卷（总纲 / 卷纲）

锁卷纲前按此顺序，禁止从章合同倒推卷目标。

1. **定高潮**：本卷最大冲突、最强情绪、与卷目标一致。先写高潮，再填前面。
2. **切剧情单元**：每单元 = 一段章（3–8 章）一次矛盾从起到收。写 **单元卡**（节拍覆盖章范围 + 功能/目标/因果/阻碍/关键选择/形态/禁提前/下钩）。相邻单元换金手指用法或冲突形态；单元之间必须有因果。
3. **预埋信息点**：地图 / 阵营 / 人物 / 金手指 / 规则 / 矛盾 / 收集 / 感情——只标「何时露面」，不写每章任务。
4. **定开篇舞台**：切口 + 期待（新目标、升级暗示、人际扩展、新线索）。
5. **定收尾**：主线落地、奖励可见、节奏放缓、下一卷钩子。禁止在收尾打光终局底牌。

## 节点法

- **起始**：开卷谁 / 处境 / 能力（越糟越好写）。
- **终末**：卷终必须得到或失去什么（越戏剧越好）。
- **节点**：保证不偏离终末的 2–4 个跨多章成长点（不是每章一条）。
- 流派 = 主角从起始走到终末的手段。节点排好，单元卡就是这些节点的排列。

## 八节点（一卷可套）

卷纲「节奏锚点」对照本表标章位。节点可跨多章；不要拆成每章任务。

| 节点 | 任务 | 约占卷 | 节奏 |
|------|------|--------|------|
| 开篇 | 抓住读者，建立期待 | 5–10% | 快 |
| 发展 | 递进事件 + 埋伏笔 | 30–40% | 中 |
| 中点 / 转折一 | 打破预期，改格局 | 5–10% | 快 |
| 加压 / 转折二 | 赌注升级，类型与上一转不同 | 5–10% | 快 |
| 高潮 | 核心冲突正面对决 | 10–15% | 极快 |
| 余波 | 战利品可见，喘息 | 10–15% | 慢 |
| 转折三（可选） | 颠覆「已经结束」的预判，须有铺垫 | 5–10% | 快 |
| 收束 | 情感落地，留白；勿回收全部伏笔 | 10–15% | 慢 |

爽文小循环（套在单元内，不是另一套大纲）：稳定 → 危机 → 破局 → 结算 → 新平衡+预埋。

## 卷与章节奏

- **卷纲节点**：目标 → 冲突 → 中点 → 高潮 → 章位。一卷一个升级目标 + 一次主高潮。
- **剧情单元**（一段章，通常 3–8 章）：单元卡 = 节拍（章功能分配）+ 功能 + 主角目标 + 因果入口 + 核心阻碍 + 关键选择 + 主爽点形态 + 兑现归属 + 禁提前 + 下钩 + 终局边界。章合同 `unit_id` 必须指回该卡；`purpose`/`beats` 按本章在节拍中的角色下推。
- **章**（网文常见 3k–4k）：起冲突 → 加压 → 小释放或反转 → 钩子。`purpose` 从所属单元节拍下推。
- 单章钩子写在章合同 `hook`，不写进卷纲。

## 五项驱动（每 3–5 章扫一次）

1. 压力来源是否具体？
2. 解题方式是否有新意（禁止连续同金手指逻辑）？
3. 哪个认知被打破？
4. 资源/地位是否可见增值？
5. 解决后引出什么新疑问？

同类套路间隔 ≥ 3 个不同形态单元。后续单元情绪值不得显著低于前序（蓄势章除外，须在合同标明）。

## Checklist

- [ ] 开篇 3 句内有画面或冲突
- [ ] 本章目的一句话能说清（章合同 `purpose`）
- [ ] 章末钩子指向「爽点与追读」的 `hook.type`
- [ ] 章内四段式可指认；300–500 字内至少一次推进（蓄势章见上表）
- [ ] ch1–3：逐章交付项满足（见「黄金三章执行清单」）
- [ ] 本卷高潮章位已标；剧情单元覆盖本章；合同 `unit_id` 已填
- [ ] 卷纲能指回八节点中的当前位置；未提前打光终局台阶
