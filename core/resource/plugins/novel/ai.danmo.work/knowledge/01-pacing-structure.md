# 节奏与结构

长篇连载靠节奏留人：开篇抓人、章中推进、章末留钩。钩子类型与密度见「爽点与追读」。

## 黄金开篇（前三章）

开篇三基点并成一条清单，前 500 字必须落地气味：

1. **冲突先于设定**：进入利益冲突或悬念，少说明书。
2. **读者承诺清晰**：这本看爽、看虐、看悬疑？第一章就要兑现气味。
3. **主角能动**：主动选择 > 被动挨打解说。
4. **信息分层**：世界观用行动带出，不堆名词表。

**禁项（开篇即失败）：** 世界观说明书、名词表点名、被动挨打后长解说、题材公式套模具。题材只定**切口**（第一场冲突从哪进），不定章法模具。

前三章合同阶段：`search_kb` 本篇；写钩子前改查「爽点与追读」。

## 卷与章节奏

- **卷纲节点**：目标 → 冲突 → 中点 → 高潮 → 章位。卷有一个清晰升级目标 + 一次主高潮。
- **剧情单元**（一段章，通常 3–8 章）：功能 + 因果 + 主爽点形态。这是卷纲到章合同的中间层；相邻单元换形态。
- **章**（网文常见 3k–4k）：起冲突 → 加压 → 小释放或反转 → 钩子。`purpose` 从所属单元下推。
- 单章钩子写在章合同 `hook`，不写进卷纲。

## Checklist

- [ ] 开篇 3 句内有画面或冲突
- [ ] 本章目的一句话能说清（章合同 `purpose`）
- [ ] 章末钩子指向「爽点与追读」的 `hook.type`
- [ ] 本卷高潮章位已标在卷纲节奏锚点；剧情单元能覆盖本章范围
