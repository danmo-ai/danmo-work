# 仕途 / 扫黑除恶 / 都市现实

来源：番茄作家课堂《都市作品创作宝典》+ 现实向作者经验（京祺、阿刀等）。仓库无独立「仕途宝典」；本篇从**都市生活 / 现实向 / 刑侦正义线**归纳。与「悬疑 / 推理 / 探案 / 刑侦」交叉处见 `11-genre-suspense-investigation.md`。

## 定位

| 子类 | 番茄归属 | 读者来看 | 风险 |
|------|----------|----------|------|
| **仕途 / 权谋** | 都市生活 / 现实向 | 阶层、关系网、智斗、真实感 | 开篇拖沓；模仿名家故事无情感投入 |
| **扫黑除恶** | 都市现实 + 刑侦 | 小人物 vs 大势力、正义兑现 | 影射现实、审核敏感；需架空 |
| **都市生活** | 都市（非纯爽） | 共鸣、生活感悟、不套路的真实故事 | 中后期期待感弱；易陷琐碎 |

**共同要求：** 强**社会阅历与文字功底**；故事最好是「别人没讲过的」— 卖点一词/一句概括，**第一章展开**（都市生活宝典）。

**QC：** 默认 `general` 或 `male_power`（逆袭/打脸向）；权谋群像可偏 `general`；查案线叠加 `mystery` 维度。

## 都市文三分法（背景）

| 风格 | 常见题材 | 核心 |
|------|----------|------|
| 新媒体向 | 战神、女婿、都市生活 | 超强节奏、情绪、章末卡点 |
| 无线向 | 神医、奶爸、都市修真、鉴宝、重生年代 | 大框架、关系网、伏笔多 |
| 脑洞向 | 系统、神豪、直播、娱乐圈、灵气复苏 | 猎奇、快节奏、密集爽点 |

仕途/扫黑多数落在 **新媒体都市生活** 或 **传统无线都市**（关系网密、长线主案）。

## 仕途 / 都市现实：三步法

### 1. 先选故事，再定人称

- 第三人称同样可火（《余罪》）。
- **故事吸引力 > 人称**；讲「他的故事」往往比「我」更客观、更好带入（都市生活宝典）。

### 2. 用套路讲不套路的故事 — 黄金单章

- 卖点 → **一个词或一句话** → 第一章展开。
- 例：「纹身女孩」「我与纹身女孩的第一次见面」。
- **禁：** 三五章不知讲什么；长篇铺垫；模仿阿刀等只学故事不学情感 → 必陷困境。
- 基于网文环境：**遵循规律**，别开篇长篇大论（除非铁粉极多）。

### 3. 投入真实情感

- 婚姻不是人生终点：还有亲情、友情、事业、理想。
- 不必刻意埋伏笔 — **真实生活自然生长**。
- 把书写成「半个自己的人生」；情感成本决定能否写长。

## 扫黑除恶 / 仕途：结构模板

```
开篇（1–3 万字）
├─ 小人物：基层干警 / 年轻检察官 / 被排挤干事 / 举报人
├─ 核心冲突：小事暴露大问题（举报信、离奇死亡、被栽赃、证据被毁）
├─ 情绪钩：屈辱 / 愤怒 / 不公（拉满代入，天神殿式）
└─ 短期目标：保职位 / 查清首案 / 保护证人

发展（3–30 万字）
├─ 结构钩：查清 X 案 → 职级/权限提升 → 触及更大黑网
├─ 多线：事业（查案）+ 家庭（被威胁）+ 仕途（站队/压力）
├─ 配角有独立动机（禁纯工具人：抢宝物为救亲人，非为恶而恶）
└─ 每 3–5 章小冲突，每 10 章中冲突

高潮
├─ 保护伞现身 → 至暗时刻 → 证据链翻盘
├─ 伏笔回收：开篇细节（一句话、一个名字）全部兑现
└─ 结局：正义落地 + 翘尾（可留新案）

中期不崩
├─ 开篇几万字埋长线；每 3–10 万字揭伏笔
├─ 重要配角退场推新冲突
└─ 不换地图（禁突然跑国外）；靠关系网扩展
```

**与「强约束」：** 布局/权谋/群像可借力，但**因果权与结算权**仍须主角侧可见；不能把高光无声交给机构。见「题材与平台 → 番茄战神 vs 权谋」。

## 新媒体向可借节奏（非仕途专类，但情绪有用）

| 技法 | 仕途/扫黑应用 |
|------|----------------|
| 小人物逻辑 | 基层「不公平对待」引发共鸣 |
| 情绪延续 | 开篇屈辱/愤怒勿突兀转场，要极致化后再翻 |
| 章末卡点 | 证据被毁 / 上级施压 / 证人失踪 / 被调离 |
| 身份反差 | 看似废柴干事，实则隐藏背景或关键证据 |

**女婿/战神底层逻辑（借情绪，非必用赘婿设定）：** 下沉小人物 + 金手指/隐藏身份解决冲突 → 期待感。仕途版：明面弱势身份 + 暗中资源/证据/人脉。

## 人物（现实向）

**京祺 / 风雨如书共识：**

- **真实 = 尖锐 + 两面性**；人不只有真善美，可自私、可选择性做坏事。
- 主角开局**可不讨喜**（懦弱、自卑），在挫折中生长更真实。
- 反派须探索「变坏的深层原因」，非纯恶人。
- 刑侦/扫黑主角：沉默寡言、内心丰富、遇困不抱怨、用努力解决（陈池式）。

见「人设与群像 → 四件套、矛盾、三锚点、配角非工具人」。

## 冲突设计

高尔基式四特点：**尖锐激烈、高度集中、进展紧张、曲折多变**。

| 来源 | 仕途/扫黑例 |
|------|-------------|
| 人与人 | 上下级、同盟背叛、家属被威胁 |
| 内心 | 保家 vs 报国、程序 vs 结果、真相 vs 稳定 |
| 与环境 | 体制压力、舆论、资源不对等 |

**禁宽泛冲突：** 开篇「生死抉择」无代入；用**具体利益**（职位、证据、家人、名誉）。

**道德挑战 + 时间锁 + 空间锁：** 见 `11-genre-suspense-investigation.md`；扫黑常叠加「限期移交 / 隔离审查 / 封闭调查组」。

## 开篇雷区（与 07 / 01 一致）

- 堆砌朝代背景、家族关系上千字才出主角。
- 日常上班挤公交式平淡切入。
- 信息轰炸：大段世界观、势力分布。
- 人物过多、视角乱跳。
- 大段环境/外貌描写（无关剧情 >100 字警惕）。

**改进：** 黄金三章；冲突/悬念开篇；信息分层（身份照镜子带出，关键规则在剧情节点揭）。

## 书名 / 简介 / 包装

- 传统/新媒体都市：**简单大气**，禁无脑蹭无关热点。
- 男频现实/扫黑：封面偏**深、冷色**。
- 简介：**首行核心梗 → 高能冲突 → 300 字主线 → 钩子问句**。
- 禁：文艺堆砌、剧透全文、文不对题（悬疑梗配甜宠简介）。
- 签约后：**多书名实验**（≤5 组，7–10 天），须有区分度，禁骗点击。

## 审核与合规（hard）

| 禁止 | 建议 |
|------|------|
| 真实案件影射、可识别在职官员 | 全部架空 |
| 影射现实政治 | 禁 |
| 正义靠私刑 / 超自然代替法治 | 须依法绳之以法 |
| 涉黑势力脸谱化「为坏而坏」 | 动机链完整 |
| 过度血腥、屠城 | 模糊化 |

与悬疑 KB 共用红线：无真实地名/机关名/领导人名；陋习禁写；三观须正。

## 更新与长线

- 章 **2000–3500** 字；章末钩（「题材与平台 → 番茄平台」）。
- 都市**不宜换地图**；空间局限内用关系网、新冲突、伏笔揭环推剧情。
- 中期瓶颈：埋伏笔、配角冲突、金手指/资源阶段性释放。
- 稳定更新影响推荐；断更伤数据。

## 第一章 Checklist

- [ ] **具体冲突**（非「我从政了」式介绍）
- [ ] 小人物遇大事，或大人物遇委屈小事
- [ ] 情绪明确：愤怒 / 屈辱 / 不公
- [ ] 卖点一句话可说清（「一张举报信」「被栽赃的录像」）
- [ ] 主线目标第一章抛出（查什么 / 保什么 / 证明什么）
- [ ] 反派/黑势力有动机，非工具人
- [ ] 架空处理，不影射现实
- [ ] 章末钩具体（非口号）
