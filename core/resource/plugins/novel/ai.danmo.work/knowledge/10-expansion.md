# 扩写与字数控制

字数不达标是症状不是病：先分「赶/薄/欠戏剧化」还是「紧/快/完整」。

## 判断

- **赶、薄、欠戏剧化** → 扩写（技术见 `novel-write/references/expansion.md`，每章 ≤3 种）。
- **紧、快、完整但短** → 调整章纲 `word_target`（找用户确认），不要注水。

## 七技术速查

场景细节充实 / 内心独白 / 对话扩写（潜台词谈判）/ 感官层次（主导感官 +2-3 其他）/ 副线编织 / 节奏调制（关键时刻 1 段拉 3-5 段）/ 氛围构建（环境作情绪镜像）。

## 纪律

1. 每章最多 3 种技术；删掉不弱化章节 = 注水。
2. 扩写段落仍须有张力；不拖慢快节奏章节。
3. 背景倾倒、设定讲座、总结叙述不算扩写。
4. 仙侠玄幻**忌扩写打斗**；推理**忌独白泄密**；恐怖**忌副线破氛围**。
5. 扩写后重跑 gate precommit。

## Checklist

- [ ] 确认过不是结构问题（缺场景 → 改 beats）
- [ ] 本章 ≤3 种技术且能说出是哪几种
- [ ] 每段扩写都能回答「删了会怎样」
