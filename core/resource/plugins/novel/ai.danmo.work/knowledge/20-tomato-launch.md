# 番茄发布与冷启动

创作层（写得好）和发布层（推得动）是两件事。本篇管发布层：书名、简介、标签、章节标题、免费/付费章差异、更新节奏、上架节点。**平台规则会变，具体数字以番茄作家后台当前规则为准**，本篇讲方法不讲死数字。

## 三件套：书名 / 简介 / 标签

冷启动读者看到的第一屏是这三件，不是正文。写得再好，三件套不抓人，没人点进来。

### 书名

公式：**身份/处境 + 冲突/悬念 + （可选）类型词**。

| 正例方向 | 反例 |
|----------|------|
| 《重生之我在警局当法医》（身份+处境+类型） | 《岁月长河》（无冲突无类型） |
| 《开局捡到失忆大佬》（动作+悬念+关系） | 《云深不知处》（纯文艺无信息） |
| 《我在精神病院学斩神》（反差+动作+悬念） | 《某某传》（generic） |

纪律：
- 书名里最好有**一个动作或一个反差**，不要纯意境。
- 男频：爽点/金手指/身份尽量外露；女频：关系/反差/情绪点外露。
- 不蹭具体 IP / 真实人名 / 热点事件名。
- 书名长度控制在番茄展示位不截断（通常 8-15 字最佳，以后台展示为准）。

### 简介（三行结构）

| 行 | 任务 | 写法 |
|----|------|------|
| 第一行 | **钩住** | 一个具体冲突或反差，不是"他重生了"这种陈述 |
| 第二行 | **主角+金手指** | 主角是谁、能干什么、要什么 |
| 第三行 | **悬念/爽点预告** | 读者追下去能看到什么 |

纪律：
- 简介不超过 100-150 字，不写小传，不写世界观设定。
- 不写"请看正文"这种废话。
- 男频简介把金手指/爽点外露；女频简介把关系张力外露。
- 简介里**不许剧透终局反转**。

### 标签

- 选番茄后台提供的推荐标签，选**和本书题材一致**的，不蹭不相关高流量标签（会歪推荐池）。
- 主标签 1-2 个定题材（如"悬疑""职场"），辅标签 1-2 个定爽点形态（如"爽文""打脸"）。
- 标签和书名、简介必须自洽，否则算法把书推给错的人，读完率崩。

## 章节标题

番茄章节标题直接影响点击率（读者在目录页决定点哪章）。

公式：**本章关键事件/悬念，不写抒情短语**。

| 正例 | 反例 |
|------|------|
| 第三章 死者的第三根手指 | 第三章 初遇 |
| 第七章 他拿出了那枚戒指 | 第七章 暗流 |
| 第十二章 审讯室里的电话 | 第十二章 交锋 |

纪律：
- 章节标题里**最好有一个具体物件/动作/数字**。
- 不写"风起""暗涌""抉择"这种虚词。
- 关键反转章的标题可以半剧透钩子（"他摘下面具"），但不剧透谜底。

## 留存三跳点

番茄读者刷得快，首章有三个跳出高危点。**这三个点必须放东西**。

| 跳点 | 位置 | 必须有什么 |
|------|------|-----------|
| 第一跳 | 前 300-500 字 | 主角身份可辨 + 一个具体冲突或异常气味 |
| 第二跳 | 前 1500-2000 字 | 金手指/核心设定第一次**显现**（不是解说） |
| 第三跳 | 章末 | 一个具体钩子（见"爽点与追读"九类钩） |

纪律：
- 第一跳不许是天气/日常/背景铺垫（见"节奏与结构"六种禁用开头）。
- 第二跳不许是设定讲座——金手指要在**动作里**露出来，不是主角坐下来想"我有个系统"。
- 第三跳不许是感悟式结尾（"或许，这只是个开始"）。

## 免费章 vs 付费章

番茄通常前若干章免费（具体章数以后台当前规则为准），后面付费。两段写法不同。

| 段 | 任务 | 写法 |
|----|------|------|
| 免费段 | **让读者追下去** | 节奏更快、钩子更密、爽点更早兑现；第一章必须立住题材气味 |
| 付费段 | **让读者愿意花钱** | 第一次付费章前必须有一个**小高潮或大钩子**；付费后第一二章不能立刻松 |

纪律：
- 免费段不堆设定、不慢热、不让主角被动挨打超过半章。
- 付费章开启点附近，免费段最后一章必须是**强钩或小高潮**，不是过渡章。
- 付费后不能"水两章再爽"——读者刚花钱，第二章就得给一个兑现。

## 更新节奏与存稿

| 项 | 建议 |
|----|------|
| 日更字数 | 番茄主流日更 4000-6000 字（2-3 章），以全勤/推荐规则为准 |
| 存稿缓冲 | 开书前至少备 **1 个单元**（3-8 章）存稿，防断更 |
| 上架前 | 建议备到**第一卷结束**，上架后不断更 |
| 断更 | 断更超过推荐算法容忍期会掉推荐，存稿就是保险丝 |

纪律：
- 不为了爆更写水文（见"扩写与字数控制"——卡文时砍冗余，不凑字）。
- 固定更新时间，让读者养成追更习惯。

## 上架节点

- 番茄上架通常在**积累一定字数和追读**后（具体门槛以后台为准），不是开书即上架。
- 上架前要确认：
  1. 第一卷主线已经立住（读者知道这本看什么）。
  2. 有一个**未兑现的大钩子**等读者付费追。
  3. 主角金手指/核心关系已经第一次显现。
- 上架章节附近不要放纯过渡章。

## 本章说与评论区（留存放大器）

番茄的"本章说"（读者弹幕）本身是留存工具。

- 写正文时**留可弹幕点**：一个反差、一个冷知识、一个"这不科学"的细节，读者会自发发弹幕。
- 关键反转章不要把话说满，留一句让读者猜——猜的过程就是评论区和弹幕。
- 作者可以在章末留一个**开放式问题**（不剧透），引导评论。
- 不要在正文里硬塞"求评论求订阅"——番茄读者吃自然，不吃乞讨。

## 番茄向 vs 其他平台

立项敲定目标平台后只走一轨；硬数字以后台为准。

### 风格 1 · 番茄默认（本篇硬指标）

| 维度 | 取向 |
|------|------|
| 读者耐心 | 秒划；三跳点必须有货 |
| 爽点 | 早、密；金手指动作里早现 |
| 段落 | 短（≤3 行一段） |
| 群像 | 主角视角为主，配角少抢戏 |
| 情感 | 可撕裂式爆发；male_power 加压见「爽点与追读」风格 1 |
| 核心指标 | 读完率、追读率 |

### 风格 2 · 起点向

| 维度 | 取向 |
|------|------|
| 读者耐心 | 愿读慢热设定 |
| 爽点 | 可铺垫更长；信息增量驱动（每章有新知，不只情绪） |
| 段落 | 可稍长 |
| 群像 | 配角可有独立高光与弱点 |
| 情感 | 安静感动也可成立 |
| 核心指标 | 订阅、收藏；养肥后再爆发，反馈滞后 |

### 其他频道（对照，不另开篇）

| 平台 | 节奏要点 |
|------|----------|
| 晋江 | 感情线优先、心理密度高；安全感与关系选择见「现代言情」「古代言情」 |
| 七猫 | 开篇亮点/标签密度高；女频微创新见言情篇；OS 拐杖见「文风与去 AI 味」 |
| 盐选短篇 | **风格 2 短篇轨**见「题材与平台」；不走本篇长篇三跳点配额 |

**通用不变：** 章末钩、金手指不代劳、去 AI 味、话疗禁令——跨平台都成立。

## AI 签约与同质化

平台在收紧低质 AI 稿（结构混乱、转折生硬、逻辑割裂、指令残留）。过审靠：人主导契约与关键抉择、章纲满再扩写、deslop 过 gate、人工重写核心对白与转折。不依赖第三方检测分数当唯一标准。

## Checklist

- [ ] 书名有动作/反差/类型词，不是纯意境
- [ ] 简介三行：钩住+金手指+悬念，150 字内，不剧透终局
- [ ] 标签和书名/简介自洽，不蹭不相关标签
- [ ] 章节标题有具体物件/动作/数字，不是"暗流/抉择"
- [ ] 首章三跳点都有东西（500字冲突/2000字金手指显现/章末钩）——短篇轨除外
- [ ] 免费段节奏快，付费章前有小高潮或强钩
- [ ] 存稿≥1单元，固定更新时间
- [ ] 上架前第一卷立住、有未兑现大钩
- [ ] 正文留了可弹幕点，不硬求评论
- [ ] 目标平台轨（风格 1/2）与 novel-state 一致
