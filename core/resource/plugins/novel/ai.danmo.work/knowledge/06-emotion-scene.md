# 情绪与场景

读者追的是情绪曲线，不是事件清单。按章合同 `beats` 加载对应场景节。

## 情绪定调

动笔前先定本章主情绪：爽 / 虐 / 慌 / 暖 / 悚 / 窘。多情绪可以，但要有主次。钩子选型跟主情绪走，见「爽点与追读」。

## 期待管理

- **承诺**：开篇或卷首暗示的爽点/谜底，要在可感知窗口内推进。
- **延迟**：延迟要加代价或新信息，不能空拖。
- **反转**：类型是信息 / 身份 / 立场 三选一写进节拍；时机放在释放前或钩子上。反转前每个关键细节应可回看成立（公平戏）；误导路径须在前文留过可检索的假因，禁止无铺垫变卦。

| 类型 | 读者误以为 | 实际是 |
|------|------------|--------|
| 信息 | 缺一块事实 | 事实一直在，解读错了 |
| 身份 | TA 是谁 | 标签翻转（须早埋气味） |
| 立场 | 敌/友固定 | 利益或信念改边 |

自检：回看前文，假因能否被检索到？收益结算给谁（见「强约束」四问）？

## 代入

- 具体欲望 + 具体障碍 > 空洞「很努力」。
- 让读者比配角多知道一点或少知道一点（信息差）。
- 失败要疼：损失资源、面子、关系或时间。

## 对话场景

- **性格差**：每人说话方式不同（句长、用词、回避/直给）。
- **潜台词**：表面话题 ≠ 真实诉求。
- **信息控制**：先定「谁已经知道什么」；对白只放出章合同 `info_control.reveals` 允许的部分。
- **功能**：推进冲突 / 暴露信息 / 关系位移——每段至少完成一项。
- **节制**：连续 5 轮无新信息 → 砍或换动作。
- **解释型对白判定**：角色把作者注释说给另一个已知情的人听（「你知道的，我们宗门有三禁……」）→ 删，改成行动或对不知情者施压。

## 打斗 / 对决

1. **态势**：谁占上风、环境约束
2. **交换**：2–3 个有代价的攻防
3. **转折**：规则/道具/心理破点
4. **落点**：胜负或僵局 + 身体/资源代价

禁止：纯招式名堆砌、无代价秒杀、战力突然跳档无铺垫。

围观分层：路人震惊 < 懂行的人改口 < 高层报价/站队。熟人震惊远爽于群演起哄。打脸围观见「爽点与追读」释放链。

## 系统流 / 面板

- 面板信息 **≤3 行关键数据**；其余进内心或后续章。
- 系统说话要有 **人格或机械感二选一**，勿混。
- 奖励即时但 **代价同步**（冷却、任务、暴露风险）。
