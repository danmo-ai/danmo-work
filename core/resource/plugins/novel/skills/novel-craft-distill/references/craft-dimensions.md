# Craft dimensions（手法四维）

每维：观察什么 → 写成可执行旋钮（1–5 或短规则）。只记「怎么写」，不记「写了什么」。

## 1. Language（语言）

| 观察 | 写成 |
|------|------|
| 平均句长、长短交替 | `sentence_length` dial + 「短句冲刺 / 长句铺陈」规则 |
| 语域（古风/白话/书面/口语） | 固定语域标签 + 禁混规则 |
| 修辞密度（比喻、排比、通感） | 上限/偏好；忌空标签如「文笔优美」 |
| 标点习惯（破折号、省略号、短段） | 密度偏好；与去 AI 通用规则冲突时以本书技法为准并注明 |
| 用词温度（冷硬/温润/讽） | 一句话定性 + must_avoid 套话 |

## 2. Narrative（叙事）

| 观察 | 写成 |
|------|------|
| POV（第几人称、单/多、距离远近） | `pov_discipline`：默认视角 + 禁跳规则 |
| 展示 vs 讲述比例 | `show_tell` dial |
| 信息释放（露一藏九、倒叙、补叙） | 节奏向规则，**不写具体伏笔内容** |
| 场景切入（动作进 / 对话进 / 环境进） | 开场偏好列表 |
| 叙述者态度（中立/带偏/不可靠感） | 语气旋钮，不写角色名 |

## 3. Dialogue & interiority（对话 / 内心）

| 观察 | 写成 |
|------|------|
| 对话占比 | `dialogue_ratio` 约 % + dial |
| 对白长短、打断、潜台词 | 对白形态规则 |
| 标签风格（「说」为主 vs 动作替代） | tag 偏好 |
| 内心戏占比与形式（自由间接 / 直述） | `interiority` dial |
| 角色声口差异手法 | **手法**（用词层/节奏层），不写具体人物声线档案 |

## 4. Pacing & emotion（节奏 / 情绪）

| 观察 | 写成 |
|------|------|
| 章/段节奏（密-疏交替） | `pacing` dial + 段落长度习惯 |
| 高潮前蓄力方式 | 可复用手法，不写具体高潮事件 |
| 情绪温度曲线（冷起热收等） | `emotion_temp` dial |
| 章末钩子类型偏好 | 类型标签（悬念/反转预告/决策点），不写本书钩子剧情 |
| 收束忌讳（鸡汤总结、口号升华） | 写入 `must_avoid` |

## Dial 刻度（统一 1–5）

写清两端含义，避免裸数字：

- 例：`show_tell: 4` → 「偏展示；说明句只在转场/时间跳跃用」
- 例：`dialogue_ratio_dial: 3` → 「对话约占 35–45%；余下叙事推进」
