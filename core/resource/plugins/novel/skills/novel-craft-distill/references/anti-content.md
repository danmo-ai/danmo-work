# Anti-content（禁止写入产物）

本技能只蒸馏**写法**。下列内容出现在输出文件中 = 质检失败。

## 剔除清单

| 类别 | 示例（勿写） |
|------|----------------|
| 情节摘要 | 第3章反派劫走人质 |
| 专有人名 / 化名档案 | 林雪、宿敌真身设定 |
| 地名 / 势力专名设定 | XX宗门等级表 |
| 金手指 / 系统规则 | 每日签到得积分 |
| 伏笔与回收表 | FS-001 失踪信 |
| 时间线 / 编年 | 三年前灭门 |
| 角色关系网 | A 暗恋 B |
| 主题说教 / 作品评价 | 「本书深刻反映…」 |
| 长引文 | >200 字连续摘录 |

## 允许的「近边界」写法

- 「第三人称有限，跟随主视角，禁上帝视角插叙」——OK（视角纪律）
- 「章末偏好未完成的决策点，避免鸡汤升华」——OK（钩子**类型**）
- 「对白短句打断，少用『说道』堆砌」——OK（对话手法）

## 与本书创作文件的切割

| 职责 | 位置 | 本技能 |
|------|------|--------|
| 技法文档 | 用户指定或 `craft/*-craft.md` | **只写这里** |
| 文风指纹 / 圣经 / 人物 / facts | `novel/<book-id>/…` | **不写、不改** |
| 通用去 AI / 题材 KB | `kb-novel-craft` | **不改** |

续写书的内容 DNA / Frozen_Canon 仍走 `novel-write` continuation，不混进本产物。
