# Sampling（长文取样）

目标：用尽量少的正文覆盖四维信号，避免通读全书进上下文。

## 短源（约 < 8k 字或单文件摘录）

- 全文可读则通读；否则取头/中/尾三段。
- 强制 `confidence: low`。
- 不足则在 Meta 注明「样本不足，dials 为估计」。

## 长源（多章 / 全书）

按块采样（改编自 NovelDistiller 流程，手工步骤）：

1. **分块**：按章或按固定窗口（建议 2–4k 字/块）列出目录，不一次性加载全书。
2. **智能采样**（每类至少 1 块，能辨认则优先）：
   - 章首（建场 / 语域）
   - 章中（日常推进 / 句式基线）
   - 章末（钩子形态）
   - 对话密段（对白节奏）
   - 高潮或高冲突段（节奏与情绪上限）
3. **批次压缩**：每块先写 3–5 条手法观察（仍禁剧情专名），再合并去重进最终文档。
4. **全书画像**：合并时只保留稳定重复的手法；偶发修辞标为「偶发，不强制」。

## 禁止

- 为「完整剧情」而顺序读完全书。
- 采样笔记里留下可识别的人名地名剧情句（应用「他/她/该地」替换后再写入产物）。
