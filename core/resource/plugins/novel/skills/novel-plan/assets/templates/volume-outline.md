## 剧情单元

每单元覆盖 **一段章**（通常 3–8 章）：一次**矛盾**从起到收（欲望 + 阻碍）。用 **单元卡**（勿再写扁表）。相邻单元换金手指用法或冲突形态；单元之间必须有因果。

章纲 `unit_id` = `v{{NN}}-U#`（如 `v04-U2`）。缺单元卡、节拍未覆盖章范围、或对不上 → 退回补卷纲，禁止空造章纲。

**单元节拍**只标章范围 + 功能词（建立期待→尝试→加压→决断→兑现→余波），可按题材删并。禁止把节拍写成每章四列细纲，禁止在此写单章 `purpose` / `pleasure_point` / `hook.out`。

连续 3 个单元同一主爽点形态必须重排。章纲从所属单元卡下推（见文末下推提示）。

**字段顺序（欲望→阻碍→选择→兑现→下钩）：** 勿打乱；`单元功能` 等关键词勿改名（gate / 下推依赖）。
