# Expansion（字数不足时的扩写纪律）

Draft 达不到章纲 `word_target` × 0.6（gate precommit advisory）或明显「赶、薄、欠戏剧化」时使用。
短而「紧、快、完整」的章节**不要硬扩**——找用户确认调整 `word_target` 更合适。

## 总规则

- **每章最多用 3 种技术**，在章纲或修订说明里注明用了哪几种。
- 一切扩写必须服务故事：删掉该段会弱化章节才算有效扩写，否则是注水。
- 扩写段落仍须有张力（冲突/悬念/新信息至少其一）。
- 快节奏章节不拖慢：宁改目标字数。
- 背景倾倒、设定讲座、总结叙述**不算扩写**。

## 七种技术

### 1. 场景细节充实
加 POV 角色的感知细节，优先**非视觉**感官（气味/触感/声音/温度）。
- 何时用：建立场景、转场后。何时不用：动作场景中段。

### 2. 内心独白
决策点暂停动作，展示权衡与矛盾欲望（想要 A 也想要 B，互相冲突）。
- 何时用：重大选择前、反转后。何时不用：动作中段、琐事。

### 3. 对话扩写
交易式对话 → 表层之下的谈判：A 想要什么、B 想要什么、都不直说（潜台词）。
- Before: 「你昨晚在哪？」「加班。」
- After: 她拨着杯里的枸杞，没抬头。「昨晚几点回的家？」——问的是时间，试的是谎。
- 何时用：关系临界、审问、谈判场景。

### 4. 感官层次
识别场景主导感官（通常是视觉），加 2–3 个其他感官。

| 场景类型 | 感官调色板 |
|----------|-----------|
| 打斗 | 痛觉、汗味、耳鸣、地面震动 |
| 亲密 | 体温、呼吸节奏、织物触感 |
| 侦查/探索 | 灰尘味、回声、光线变化 |
| 自然旅途 | 风向、湿气、虫鸣、脚下质地 |
| 餐饮社交 | 味道层次、餐具声、席间沉默 |

### 5. 副线编织
从 ledger Open loops / 章纲 `info_control` 找该推进的副线，织入主线场景（背景里的一次照面、一句转述）。
- 何时用：主线单薄的章节。何时不用：高潮章、开篇章。

### 6. 节奏调制
把最重要的时刻从 1 段拉成 3–5 段：微节拍 → 身体感觉 → 时间感知变慢 → 他人反应，依次呈现。
- 何时用：卷高潮、关键揭示、死亡/反转瞬间。

### 7. 氛围构建
环境作情绪镜像：移情（景随情变）、反讽对比（喜事在灵堂般寂静中宣布）、环境压力（逼仄空间加压）、沉默与空无。

## 体裁优先级

| 体裁 | 优先 | 忌 |
|------|------|-----|
| 文学 | 独白 / 氛围 / 感官 | 为长而长 |
| 惊悚 | 节奏调制 / 对话扩写 | 长独白泄压 |
| 言情 | 对话扩写 / 感官 / 独白 | 副线抢戏 |
| 玄幻仙侠 | 场景细节 / 氛围 / 副线 | **过度扩写打斗（读者会跳过长打斗）** |
| 推理 | 对话扩写 / 场景细节藏线索 | 独白泄密 |
| 恐怖 | 感官 / 氛围 / 节奏调制 | 副线破恐怖感 |

## 与流程的衔接

1. 扩写前先确认不是结构问题（场景缺失 → 改章纲 beats，回到章纲）。
2. 扩写仍是改 `chapters/chNNN.md` 同一文件，就地覆盖，不搞版本增殖。
3. 扩写后重跑 gate `precommit`（字数 advisory 应消失；不得引入新的 deslop blocking）。
