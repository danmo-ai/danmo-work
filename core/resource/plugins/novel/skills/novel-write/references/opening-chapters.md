第 1–3 章专用。与 KB「节奏与结构 → 黄金开篇 / 黄金三章执行清单」、`题材与平台 → 番茄平台` 对照使用；不替代章纲。

## When to load

- 写 / 审 / 续写 **ch001–ch003** 正文前。
- 用户点「开写下一章」且下一章索引 ≤3。
- 批次冻结含前三章时，写前预检一并加载。

## Preflight add-on

在 `chapter-write.md` gate CONTEXT 之外：

1. `read_skill` 本文。
2. `search_kb` **节奏与结构**（黄金三章 + 章内节奏）。本阶段至多再加 1 次「题材与平台」（番茄向）。
3. 确认 ch001 章纲 `purpose` 含「读者承诺」一句（爽 / 虐 / 悬疑 / 情感——四选一写进章纲，不写进正文）。

## 三章分工（每章只交付一行核心）

| 章 | 读者离开时必须带走 | 禁止 |
|----|-------------------|------|
| **ch1** | 冲突已发生 + 主角能动 + 题材气味 + 章末钩 | 世界观说明书、名词表、被动挨打长解说 |
| **ch2** |  stakes 抬高 + 小代价或小胜利（二选一可见）+ 章末钩 | 重复 ch1 冲突形态、空转聊天、系统面板 >3 行 |
| **ch3** | **一个完整爽点/情绪闭环**（压抑→蓄势→释放→余韵，见 KB 爽点与追读）+ 读者知道「这类书看什么」 | 仍不兑现承诺、钩子是口号、第三卷才该出现的大高潮 |

前三章合起来 = **一个可复述的 mini 承诺**：「这本书讲 X 的人，在 Y 压力下，靠 Z 方式推进。」

## 字数与节奏预算（番茄默认 2000–3500/章）

| 区间 | ch1 | ch2 | ch3 |
|------|-----|-----|-----|
| 章首 500 字 | 画面或冲突入场；**300 字内**主角+冲突+金手指/异常气味 | 500 字内接住 ch1 `hook.out`（动作/对白，不复述） | 500 字内接住 ch2 钩；可给微兑现或加压 |
| 章中 60–70% | 加压 + 信息分层（行动带出设定） | 新障碍或关系位移；章内每 **300–500 字** 有新信息/新压力/关系变化 | 蓄势 → 释放（可小可中，须可命名） |
| 章末 10–15% | `hook.out` 具体事件 |  stakes 再抬或身份/信息半揭 | 闭环余韵 + 下一单元钩子 |

章内四段式与铺垫密度细则 → KB「节奏与结构 → 章内节奏」。

## 逐章验收（写后 / 审前勾选）

### ch1

- [ ] 前 3 句有画面或冲突（非天气/起床流水）
- [ ] 主角至少一次 **主动选择**（哪怕选错）
- [ ] 金手指/核心设定 **气味** 到场（不必全解释）
- [ ] 无连续 200 字以上纯设定解说
- [ ] 章末 `hook.out` 是 **事件** 非口号

### ch2

- [ ] 章首 500 字内接住 ch1 钩
- [ ] 冲突形态与 ch1 **不同**（换场景、换对手层级或换矛盾类型）
- [ ] 可见 **小代价**（丢面子/资源/时间）或 **小胜利**（读者能指认）
- [ ] 章末钩指向 ch3 将要闭合的爽点/情绪

### ch3

- [ ] 章首 500 字内接住 ch2 钩
- [ ] 本章有 **可命名** 的释放（打脸/揭秘/关系位移/生存破局——写进章纲 `pleasure_point`）
- [ ] 释放前有可见压抑或蓄势（非空降）
- [ ] 读者能回答：「这类书主要看什么？」
- [ ] 章末钩引向 **下一单元**（不是本书终局）
