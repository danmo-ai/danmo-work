# Scene routing（场景专项路由）

章合同 `beats` 含场景标签时，加载 KB「情绪与场景」对应小节。**标签管加载哪一节；五感动线怎么写见 KB → 场景沉浸。**

## Beat 标签 → KB

| Beat 关键词 | 加载 |
|-------------|------|
| `scene:establish`、建立场景、入场、环境 | KB 情绪与场景 → **场景沉浸** |
| `scene:transition`、转场、换场、过渡 | KB 情绪与场景 → **场景沉浸**（过渡拍） |
| 地点名 + 首次上场（如「地下牢」「拍卖厅」） | KB 情绪与场景 → **场景沉浸** |
| 对话、谈判、争吵 | KB 情绪与场景 → 对话场景 |
| 打斗、对决、战斗 | KB 情绪与场景 → 打斗 |
| 系统、面板、签到、任务 | KB 情绪与场景 → 系统流 |
| 无标签 | 通用文风 KB；**首个 beat 仍建议 1 锚点 + 入场动线**（沉浸节摘要） |

## 流程

1. 扫描合同 `beats` 列表。
2. `search_kb` / `get_kb_doc` 情绪与场景 — 按上表 **只加载命中** 的小节，勿通读整篇。
3. 写正文时 beats 顺序与合同一致。
4. 场景切换：KB **场景沉浸 → 过渡拍**（时间/动作/感官三选一）；禁止硬切。

## 与 chapter-write 联动

`chapter-write.md` preflight 后调用本路由；不在无标签时机械套三阶结构。ch1–3 首 beat 多为 establish → 优先沉浸节。
