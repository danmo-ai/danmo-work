# Scene routing（场景专项路由）

章合同 `beats` 含场景标签时，加载 KB「情绪与场景」对应小节。

## Beat 标签 → KB

| Beat 关键词 | 加载 |
|-------------|------|
| 对话、谈判、争吵 | KB 情绪与场景 → 对话场景 |
| 打斗、对决、战斗 | KB 情绪与场景 → 打斗 |
| 系统、面板、签到、任务 | KB 情绪与场景 → 系统流 |
| 无标签 | 仅通用文风 KB |

## 流程

1. 扫描合同 `beats` 列表。
2. `search_kb` / `get_kb_doc` 情绪与场景。
3. 写正文时 beats 顺序与合同一致；场景切换有过渡拍。

## 与 chapter-write 联动

`chapter-write.md` preflight 后调用本路由；不在无标签时机械套三阶结构。
