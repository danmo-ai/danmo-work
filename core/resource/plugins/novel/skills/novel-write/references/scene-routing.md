# Scene routing（卡文 / 场景救援例外）

**不是** `unit-write` 短路径的默认步骤。短路径：只读 write pack → 一次 write → seal，**0 次 `search_kb`**。pack 已含章级 beat、题材 bullet、指纹；不要为本页再检索。

仅当用户卡文 / 点名「场景沉浸、对话、打斗」救援，或本 turn 已按例外加载了 `opening-chapters` 且尚有 1 次检索配额时，才用本文。

## 用法

用**本 turn 已选定的那 1 次** `search_kb`，只加载命中小节。不要通读整篇，不要为本页再 `read_skill`，不要为场景再开第二次检索。

默认检索「情绪与场景」（KB `06`）。仅当 `subgenre=刑侦探案` 且本 turn 已查「刑侦人味文风」时，改走下表人味列。

**对话类 beat：** 先看 pack 章级 beat / 细纲里本场的 `潜:`（`subtext`），再决定是否把这一次 KB 用在「对话场景」——已有清晰潜台词时可不再检索。
