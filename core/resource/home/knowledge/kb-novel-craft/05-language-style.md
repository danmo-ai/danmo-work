# 语言与文风

文风是可复用资产：先锁定，再写章。

## 视角选择

- **有限第三人称**（网文常见）：贴主角感知，利于悬念。
- **第一人称**：声音强，但知情人边界更严。
- 一章内不乱切上帝视角；多 POV 需在合同标明。

## 画面感

优先：动作、对话、感官细节 → 再补判断。  
少用抽象总结句（「他感到前所未有的震撼」）替代可见行为。

## 对话指纹

- 每人有口头禅/回避点/信息密度差异。
- 对话推进利益或揭示性格；删除纯复述已知信息的对白。

## 文风分层（可记入 project memory）

| 倾向 | 特征 | 适合 |
|------|------|------|
| 热血爽文 | 短句、快切、释放密 | 玄幻升级 |
| 都市烟火 | 生活细节、对白自然 | 都市/职场 |
| 古风意境 | 留白、比兴、战写意 | 仙侠古言 |
| 悬疑压抑 | 信息克制、环境压迫 | 悬疑灵异 |

可用「反例 AI 段 + 作者改写段」提炼 8–12 条强制规则写入文风卡。

- [ ] 主要角色对白可区分
- [ ] 符合本书文风卡，未串味
